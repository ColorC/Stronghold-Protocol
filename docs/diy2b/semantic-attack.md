# 2B 普攻：参考折向、支撑与挥斩链

这是一份独立的普攻试版与原版对照。原模型和其它动作不替换。来源模型由 Git commit `67bb26c2d3d6b9e5db12282a147759a3a7b84867` 恢复，`semantic_attack.py` 只替换 `animations.Attack`，并逐项断言其它动画、骨架与皮肤数据不变。

观看入口：`/dev/diy-2b-semantic/index.html`。两边使用同一时间、同一固定相机；能慢放、暂停、逐帧、单独看手臂/剑/腿脚。分部视图在整个片段使用固定中心和比例，避免逐帧自动取景遮蔽位移。帧链接保留朝向、部位、时刻和关节/轨迹开关。

## 此次语义参考

以原姿态建立“骨盆—躯干—肩—肘—腕—握持点—剑尖”和“骨盆—髋—膝—踝—鞋底”的关系。主手对应原模型 `*_r` 链，辅助手对应 `*_l` 链；这些是稳定源标识，不据此确认角色解剖左右侧。每个视图独立读取肩肘腕、髋膝踝的有符号转角，用 `atan2(cross(elbow-shoulder,wrist-elbow),dot(...))` 保留折向。没有用无符号内角替代方向，也没有把平面投影符号视为普遍人体判据。

控制意图为蓄力、展开、挥斩和回位：上臂带动肘的位置，前臂在该姿态的折向内屈伸，手腕只有小幅局部变化。剑保持原握持偏移和长度，与手一起移动。两次攻击事件保留原时间；另一只手用小幅配合替代强制双手握同一剑柄。

双脚踝点保持原位置，足部世界朝向也保持原朝向；骨盆的小幅压低和前移交由腿链按其原折向求解。目标不可达时生成失败，避免悄悄夹紧角度形成平台。躯干、头、裙摆和头发有小幅协调和滞后，但这里不宣称已经解决质感、美感或全部动作。

正背视图并非平面镜像。背面肩肘腕的原偏移、较短的剑和大头轮廓不同，因此蓄力阶段对主上臂与前臂幅度分别校准，保留“折向、伸展、握持、支撑、阶段”这些语义，而不照搬前视局部角度。此校准属于 2B 视图适配，尚不是任意角色的自动转译器。

## 连续帧修订

首次候选保住了原姿态折向，但前视蓄力时剑大半藏在头后。第二次增加侧方蓄力，让前视剑的轮廓可见；背面套同样角度仍会遮挡。第三次按背面独立的偏移与轮廓降低蓄力转动幅度，剑在身体右侧可见。没有以数值通过代替这些图像问题。

当前仍有明显可讨论之处：主手蓄力接近颈部，躯干和重心变化偏保守，缺少不同视角下更完整的深度转身、触敌与打击反馈。当前目标是让一个简单的动作链可辨别、可查错，不能把它报告成角色动画定稿。

## 验证边界

验证脚本在真实 Pixi Spine 运行时检查四肢折向、原姿态端点、足部稳定、剑长和握持相对变换、剑尖地面，以及页面暂停、拖帧和定位链接。静态端点基准为 `Idle` 的起始相位；呼吸中段到攻击的播放衔接另行考虑，不能把不同呼吸相位混成一个端点误差。

所有连续帧、动图、浏览器回执和数值轨迹保存在 canonical 项目 `runtime/2b-semantic-attack-20261008/` 下；它们是运行证据，不是第二套动画源码。正式试版为本目录文档、生成器和 `public/dev/diy-2b-semantic/{front,back}.json`。原 atlas 和纹理由显式原路径加载，工作副本没有复制运行数据或原图片。
