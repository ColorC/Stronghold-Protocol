# 共鸣界面继承与信息布局

本轮以卫戍协议盟约网页上游 `sganggs/Stronghold-Protocol` 的 Git commit `bc50cac01ff447eff3ab6c35f69d934bbc23b48f` 为界面依据。战斗与内容数据仍使用本项目冻结的 Native 版本，不把 UI 更新替换成玩法更新。

## 页面与入口

| 状态或内容 | 直接呈现 | 展开后呈现 | 继承与调整 |
| --- | --- | --- | --- |
| 标题 | 原版场景、标题与开始入口 | 设置、继续当前进度、战术图鉴 | 保留原版标题组件与背景素材 |
| 难度 | 原版大厅难度卡与进入备战按钮 | 高级设置中的本局节奏 | 固定赛季卡池，不增加战场或主盟约选池步骤 |
| 关卡情报 | 原版关卡、敌方情报与确认入口 | 敌方详情 | 保留 BriefingScreen 与确认流程 |
| 备战 | 完整 Native 场景、部署区、备战席、左侧盟约、商店与装备库存 | 干员、盟约、装备、收入的详情 | 继承 GameScreen、FieldHost、ShopBar、DetailPanel 与布阵交互 |
| 商店 | 五张干员卡、整卡费用底色、所属盟约、固定技能图标、金币、经验、刷新与锁定 | 右键干员详情；金币展开收入与利息；经验展示概率 | 保留原版卡面与控件；信息分组参考云顶，不另造底部控制栏 |
| 干员 | Native 模型、星级与脚边已穿戴装备 | 原版技能、属性、攻击范围、盟约；装备图标展开详情 | 保留点击选中、右键详情、拖动、朝向、撤回、出售；共鸣三件装备使用一个可点击显示层 |
| 盟约 | 左侧当前阵容的盟约图标、名称与人数 | 点击盟约显示全部档位；查看全部显示整局盟约表 | 采用灰、铜、银、金、棱彩表示档位；图标统一色调，激活状态不铺高亮底色 |
| 装备库存 | 左侧独立库存栏，仅显示未穿戴的物品 | 库存管理、消耗品与合成配方入口 | 已有游戏装备素材；四件组件用明日方舟养成材料官方图标（public/css/resonance-components），其余四件组件与二十八成品分别映射，不拿组件图标充当成品 |
| 合成 | 拖动组件到库存另一组件，或干员身上已有组件 | 松开前展示合成结果；详情展示两个组件与成品 | 在现有真实装备操作上完成，不增加独立合成货币或第二套装备状态 |
| 图鉴 | 原版左下角书本入口；标题页也可进入 | 原版 Loadout 页面结构：干员、盟约、装备、配方、策略与经营规则 | 局内打开保留同一场景与连接；返回继续原局；使用完整固定卡池，不限于当前商店快照 |
| 本局信息 | 原版顶部查看按钮 | 本局策略、操作说明、最近战斗结果 | 保留原版顶部入口，不复制为一排新增按钮 |
| 收入与利息 | 商店金币与利息刻度 | 本回合收入构成、当前利息与下一档 | 使用图形、刻度及收支行，长奖励阈值默认折叠 |
| 战斗 | 原版回合、生命、敌人进度、完整实时场景、原生暂停 | 暂停后继续或离开；速度按钮切换；快结后进入真实结算 | 单人模式增加 1／2／4 倍速及快速结算，同一 Battle 持续推进，不重播、不构造胜负 |
| 回合结算 | 原版战斗完成反馈 | 战斗图表、成员贡献与收入构成 | 图形展示伤害、承伤、治疗及屏障，不改为纯文字报告 |
| 策略或补给选择 | 原版 ChoiceOverlay 卡片与确认布局 | 卡片效果、必要目标选择 | 保留稍后整理与重新打开；不重复开局选池 |
| 最终结果 | 原版 ResultScreen 的结果、阵容与统计 | 共鸣盟约与成员贡献图表 | 保留原版页面结构，文本与内容区可滚动，底部返回按钮有独立空间 |
| 设置与离开 | 原版齿轮与退出入口 | 字号、音量、画面设置；保存退出提示 | 沿用原生弹窗；本局快捷键说明匹配实际操作 |

## 参考依据与实现边界

云顶的信息层级主要参考 Riot 官方的[商店界面调整](https://teamfighttactics.leagueoflegends.com/en-gb/news/game-updates/tft-interface-update/)、[装备库存改进](https://teamfighttactics.leagueoflegends.com/en-gb/news/dev/dev-quality-of-life-improvements/)、[干员详情更新](https://teamfighttactics.leagueoflegends.com/en-au/news/game-updates/teamfight-tactics-patch-13-12-notes/)及[装备配方交互](https://teamfighttactics.leagueoflegends.com/en-us/news/game-updates/teamfight-tactics-patch-10-16-notes/)。这些资料说明相邻信息及点击层级，不作为当前赛季数值的依据。

单人暂停属于上游功能；玩家调速和快速结算是共鸣的单人便利功能。快结以较高速率推进当前模拟，仍由同一战斗产生真实结果并且只结算一次。普通盟约及其他模式的默认速度、物品槽和界面保持各自原有行为。

字号采用正文至少十六像素、辅助信息至少十四像素，并保留更大的用户设置。场景缩放与文字可读性分别处理，不用缩小字体来塞入内容。右侧详情根据实际商店边界避让；图鉴是明确打开的独立页面，关闭后回到当前战场。

真实浏览器验收覆盖标题、难度、备战、干员详情、所有盟约档位、装备和配方、收入、图鉴、设置、战斗、暂停、回合结算、选择与最终结果。检查包含横屏、命中区域、实际图片加载、文字字号、配方对比度、快捷键穿透、同场变速与自然结算。运行过程与实际回执只记在当前计划进度中。
