# 共鸣规则三内容契约

本文件约定配置、真实 Battle 和持久经营的边界，不宣称实现已完成。推演可修订适配效果及数值，必须同步唯一配置、玩家描述和验证。规则一、二仅供旧局恢复，旧规格通过 Git 查询。

## 来源和身份

人数原型为云顶 Set 13、补丁 14.23。正式输入 E:/WindowsWorkspace/webworks/apps/stronghold-protocol/data/resonance-reference/tft-set13-14.23.json 来自固定版本 CommunityDragon 客户端提取；官方页面只证明赛季背景。自然棋子、自然羁绊、条件 TeamUp、装备、强化和特殊召唤实体分开，召唤物不算自然成员。

prototype-season-build.mjs 唯一生成 shared/resonance/prototype-season.js 和同名正式 JSON/Markdown。六十个不同 charId 对应六十自然槽，一至五费数量十四、十三、十三、十二、八；二十六盟约保留真实 min/max、自然人数、费用分布和交叉关系。用户的数组是示意，禁止统一发明二人起效。领军只在一或四人起效，最高档超过自然人数须有真实转职或来源明确的额外计数。

原生国籍与组织是资料事实，战斗盟约使用中性名称。重复身份、召唤和备战不增自然人数。正式原生干员、关卡和素材通过已核验绝对目录读取，副本不复制数据、依赖或素材，不建立可写链接。

## 目录与预算

server/modes/resonance/catalog.js 合成 rulesVersion=3 的实际目录；prototype-pacts、prototype-strategies、prototype-economy 定义本季效果。冻结 legacy catalog 只服务兼容，旧国籍盟约、区域开局和转职不混入新季。

干员包含持久身份、费用、职责、合法位置、对空、固定技能、真实素材和三星彩配置。详情、变体包和图标必须使用实际选中的 skillId/iconId。不能在原生详情改技能或模组。

费用预算覆盖生命、攻击、防御、法抗、攻击间隔、技力与启动、持续、天赋、治疗、屏障、控制、对空及召唤，不能只改标价或 HP/ATK。同星、同装备、同盟约投入按可比职责进行真实 Battle 对照，高费整体职责预算更高；跨星级单列，低费三星可以超过高费一星。

来源的护甲、法抗评分不能直接当作原生平防和百分比法抗。法抗评分按 `100 × 评分 / (100 + 评分)` 转为原生减伤；盟约叠加按总评分转换差值，不能直接相加至法术免疫。护甲先以来源攻击力作为平防预算锚点，再通过实际敌方攻击与职责对照校准；这是场地和伤害体系适配，不能声称平防数字等于竞品评分。来源缺失值保留为缺失，运行使用明确的原生已知值回退，不把未知当零。

盟约与来源装备的评分增益共享实例级账本；同键替换、不同键求和后仅转换一次。原生防御天赋仍由原生系统处理。对没有竞品评分的原生关卡敌人，来源破甲按原生平防同比降低适配，保持实际命中条件、非叠加规则和持续时间，不因缺评分成为空效果。

个人签名如圣聆初雪雪地、新约能天使弹药雨和三星技能不新增伪造盟约。与原生 kit 一起安装时必须去重，不能重复施放或重复收益。

## 完整效果和选择

每项有来源版本、触发、对象、数值、持续、冷却、上限和重置。六角距离、法力、法强及玩家对战明确适配为原生格、技力、属性和关卡事件，并在来源表记录；默认文案只显示实际玩法。

全部档位需要真实消费者。临时成装、实验格、可见守卫、黑市、赞助装备、战争宝箱、家族进度和军械不能用空 hook、计量器或泛用属性冒充。每项奖励映射到可领物品、棋子、消耗品、选择或战斗实体，不静默跳过。未解码来源不进入候选。

实验格由本局种子、真实合法场地和档位格数确定，不随当前成员位置移动；准备期可见，只有站在实验格的合法实验成员获得对应的个人与共享效果。召唤守卫的双抗属于守卫，四人档标记只提高对应盟约成员对标记目标的伤害；五人、七人的专属效果分别按档位启用。

纯经营钩子在新备战和真实结果后运行，记录 battleId 以防重复。奖励进入原生模式覆盖层，支持目标、多选、放弃、收起整理和恢复。先验证钱、容量、目标与次数，再原子提交；失败不能消费进度、钱和奖励。

策略从完整同季来源强化表选编经济、经验、刷新、装备、战斗、条件任务和转职。Crest/Crown 的配套棋子及装备一起映射，不能只给徽记，不能把绝大多数候选缩成同类转职。

## 经营与装备

五格商店、九格棋子备战和独立物品库存。招募、奖励、复制、合并与出售共用份数账本，一二三星占一三九份；未买商品占份，刷新或离店归还。满备战只能在合并有合法结果位时购买。

通常十金一利息、五利息上限、二金刷新、四金四经验。本季 XP 和概率以 prototypeEconomyRules 的官方来源为准；池份单独注明版本，不能把跨版本成熟值冒充锁定补丁原值。所有开局共用同一固定名单，标准开局不重复选择。

物品 UID 和持有者 UID 分开。两组件拖到同一持有者原槽合成，库存组件也可合成并显示预览。最多三件，唯一限制针对同一持有者；满槽可以合法合成仍允许。满仓及非法目标原子拒绝，合并、出售与拆卸不丢物品。

普通配方、奖励专属、市场与軍械升级分开；缺原型组件不伪造配方，合法奖励途径保证高档可达。军械作用于稳定选定的合法成员，高星专属升级不能低星购买。

策略指定成装以源 API 对应唯一物品，不通过会覆盖别名的赞助选项反查。来源装备保留原文、变量、组成和唯一性，并实现实际被动；护盾转法强、生命阈值、持续灼烧、重伤、攻击叠速和技能暴击必须按其各自条件触发。法强适配为术法增幅，初始法力适配为当前固定技能总技力成本的百分比；文案写当前实际效果。

暴击使用一次命中解析，装备与盟约共同决定概率、技能能否暴击和额外倍率。不能让盟约与装备各自再乘一次暴击伤害。已开启技能暴击时的额外暴击伤害按来源条件启用；护盾到期增幅按固定到期时点触发，提前破盾不提前发放。

强化的防护同样进入总评分账本，不把百分比法抗与护甲评分相加。坚阵盾击先将当前双抗评分各提高5%，再按评分总和计算额外伤害；远征处决仅在实际处决成功时为处决者累计加成，普通击倒不触发，也不分发给全体。重装猛击的来源文字未明确指向敌人最大生命，本模式按持有者最大生命适配；来源中的对象不明确处保留说明，不能编成已核证的敌方比例伤害。
