# 工坊干员与装备重制

当前新局使用固定的101名干员，不设置阵营禁用。普通与进阶均保留原生技能、天赋和可选择的模组；工坊特质按其战斗、成长、经济、生成或联动定位另行配置。旧版停用干员仍可读取已有存档。

## 规模与分配依据

截至2026年10月7日，PRTS国服目录按独立干员对象统计为431项，包括异格、联动、作业平台及阿米娅另外两种职业形态。客户端表中429个可获得基础对象，加两种职业形态，与这一口径一致；召唤物、陷阱和不可获得NPC不计入。[PRTS国服目录](https://prts.wiki/w/PRTS:Gameinfo/国服/干员一览)、[PRTS数据检查](https://prts.wiki/w/PRTS:Cargo检查单)。客户端社区镜像采用原生Git版本 `a550f5e048bb94e7cdefc6eb97a4091f0c4c7add`，它不是官方托管地址。

参照2020年12月15日暗月奖品初版19.2的127种普通随从。当前映射保留野兽、龙、元素、机械、海盗及中立来源，对应排除恶魔和鱼人：按卡面族群得到105张候选，排除全族随从畸变怪后为104张，再按效果文字推断排除三张依赖恶魔的中立卡（愤怒编织者、灵魂杂耍者、晶化师），得到固定101张。三张中立卡的排除是效果文本推断，不是19.2 CardDefs subset标签确认；该固定CardDefs快照没有提供这类subset标记，因此101是设计来源池的筛选结果，不宣称是官方确证的实局池。[19.2官方公告](https://hearthstone.blizzard.com/en-us/news/23584141/19-2-patch-notes)、[固定版本CardDefs快照](https://github.com/HearthSim/hsdata/blob/cb9444afd722a16112745e5510ec191d8c813c07/CardDefs.xml)。

当前101人按正式数据中的职责分类为临时战斗14、成长41、联动22、经济5、生成13、一次性工具6。工具指获得时提供工具的角色，工具自身仍按部署或撤退事件生效。成长型按实际成长机制归类，不因带有阵营条件就归入联动型。

从现有可运行的120个干员本体中选出101个：120条本体定义保留，19条停用以兼容旧存档；新局只抽取101名活动干员。科技1–6人数为11/19/21/18/18/14，科技5–6共32名。这不是将431名干员全部加入游戏，也不是把127张随从逐张强行一对一对应101人。暗月全量译稿继续作为效果参照；现有工程部特供规则保留。

897个原生技能木桩场景覆盖120名干员、299个技能选项：单体零防零抗、单体800防40抗、四目标零防零抗各299例。每例运行90秒，无装备、无工坊特质，召唤物伤害另计入总DPS。木桩只帮助判断相应场景的输出形状和倍率，不能据治疗者的零DPS判弱；科技还考虑射程、阻挡、控制、治疗、部署周期和附带经济价值。集中表保留所有原生技能与天赋全文，并标出已有90秒探针对应的场景、技能和DPS；该输出证据不等同通用强度。

不再设置纯战斗空特质分类。玛恩纳、乌尔比安、圣约送葬人按成长定位承载对应成长；隐德来希、史尔特尔、凛御银灰按联动定位连接队伍贡献；红豆与艾丝黛尔提供临时战斗效果。治疗成长由实际有效原生治疗触发；装备治疗不回流产出，群体治疗同一施放只计一次。完全溢出的治疗不计，部分溢出但确实恢复生命的治疗仍计。原生控制、承伤、闪避、技能启动和护盾事件分别承载对应成长。

阵营使用PRTS的国家、组织、团队及所属关系，当前覆盖32个标签；不把出生地或种族当阵营。锡人可以满足所有工坊阵营特质，但它的原生阵营仍是哥伦比亚，交接资格也按原生阵营判断。新局只有幽灵鲨（科技3）和蛇屠箱（科技4）会自动带来交接凭证；资格条件对凭证持有人作为交出方或接收方均适用，另一方不需要再有凭证。其余十件旧凭证只供旧存档读取，不作为新局来源。独行者许可旧数据仍由崖心提供，惊蛰可以交给科技2–4的炎阵营干员。

## 属性乘区

徽章按件数线性增加比例，不逐件复利：攻击白值2%、基础攻速2%、生命白值3%、防御白值2%、攻击加成2%、自然技力回复基础值2%、法术减伤0.5%、初始技力为所选技能消耗2%、闪避1个百分点、每秒回复原生生命0.1%、旧生命加成徽章3%、治疗量1%、物理法术减伤0.5%、再部署缩减1%、普通攻击伤害1%。现有闪避、减伤、再部署及技力上限仍生效；原生自然回复为零的干员不会凭徽章获得虚构的自然回复。

白值与技能加攻分桶。以原生攻击1000、技能攻击加成200%为例，一件白值攻击徽章为 `1000×1.02×3=3060`；一件攻击加成徽章为 `1000×3.02=3020`。同属造成伤害加成的原生30%与新增1%加算为1.31倍；脆弱、攻速、暴击与额外伤害按其自身结算关系处理。这是用户指定的工坊乘区转换，不宣称完全复制原版所有伤害公式。[PRTS伤害与属性基础](https://prts.wiki/w/游戏数据基础)。
