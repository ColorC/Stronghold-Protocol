# 工坊干员池重制

目标：保存现有版本，以暗月奖品初版禁用后的常规单局规模和功能配比重制工坊，配置、实际规则和展示保持一致，完成真实战斗与整局测试后发布。

## 已定边界

- 干员池固定为101名可招募干员；不设置禁用位，也不再每局随机关闭阵营。
- 规模依据19.2.0.68600的127张完整随从池：七种族每局开放五种族，21种组合每局97–105种，均值101。
- 科技1–6级目标分别13/19/20/18/18/13，依据各组合均值的最大余数分配。最终允许个别交换，但总数与完整配比需要验证。
- 功能按直接主要收益统计，并另外保留联动标签。纯战斗、成长、经济、生成、机制耦合、一次性工具的参考均值分别约21.86/45.14/4.57/18/6.86/4.57，整数目标22/45/5/18/7/4。
- 技能、天赋、攻击间隔、攻击类型、目标数、技能覆盖率和生存能力共同决定科技等级。星级只保留角色事实，不直接决定科技等级；高本体输出者不额外堆重复战斗关键词。
- 机制来自暗月译稿，但允许针对实时塔防与干员自身能力调整。获得时补给只结算一次；战斗临时效果和永久增长分开；撤回、部署、出售和倒下各自结算，不重复触发获得效果。
- 百分比徽章按明示基准线性累计，禁止逐枚复利。显示与战斗、准备阶段预览使用同一规则；自身技能倍率和本体特殊属性仍按原生规则结算。
- 维持工坊已经确定的装备单形态、库存20格、装备容量999、整备区10+5、三连奖励、稀有交接凭证、合法交接损耗和普通出售销毁装备等规则。
- 源码在独立稀疏worktree修改；正式原始数据、素材和会话运行数据使用canonical绝对路径。待激活的新配置在项目任务临时区验证，完成后进入原有正式配置位置，不使正式入口依赖临时文件。

## 验收

1. 源码和线上版本分别有可恢复Git标签；配置和技能来源可追溯到原生版本。
2. 所有种子的新局都使用同一101人池，按13/19/20/18/18/13分层；无随机阵营禁用。普通/进阶和卡池份数分别验证。
3. 每人有原生能力依据、科技判断、普通/进阶机制、来源效果、角色适配理由与改编差异；全部规则有实际处理器。
4. 百分比徽章测试覆盖不同基础数值、叠加、进阶、交接损耗、技能开启、零基值或特殊回复类型及预览/实战一致性。
5. 真实Battle探针隔离本体输出；整局工具通过合法动作跑不同阵容、随机种子与难度，对比重制前后漏怪、通关、装备成长与输出分布。调整敌人只作用于工坊。
6. 相关机制测试和全仓回归通过，真实页面或既有端到端工具检查招募、部署、装备、三连、交接、特供、战斗和结束。最终集中表指向实装内容。
