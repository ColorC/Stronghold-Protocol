# 进击：大巴扎改编设计稿（2026-10-24 重写）

本文件取代 `bazaar-skill-style.md` 的卡面标准和 `.omni/tmp/assault/ak-synergy/` 的「再部署 = 第二条冷却、每张卡都有部署时效果」口径。`design.md` 里关于路线、经济、商店、遭遇的条目继续有效；本文件只管**卡怎么设计、卡面怎么写、战斗里怎么表现、上游哪些东西必须在**。

依据：大巴扎原始库 `data/assault-sources/bazaar/cards_generated.json`（1170 件英雄与通用物品、323 个技能，按原始 Trigger / Action / Duration 字段统计，脚本思路见文末）；明日方舟原表 `data/assault-sources/arknights/excel/skill_table.json`、`character_table.json`；当前公开卡面 `data/assault-rules/assault-public-text.json`（5680b1d5f）；用户 10-16 至 10-24 的全部试玩反馈。

## 0. 结论先行：前几轮为什么总不对

| 现象（用户原话） | 根因 | 本稿的改法 |
| --- | --- | --- |
| 「所有干员都有永久效果」「分布如此普遍」 | 把大巴扎的成长理解成「每张卡都要能叠」，成长还挂在战斗内事件上 | 跨战斗成长只给约 5% 的卡，且只由**局外**事件触发（§3.6） |
| 「五连击叠了多少次还是五连击」「持续一段时间少一些」 | 把方舟持续技能做成「可重复发起的 N 秒姿态」，再补一句「重复施放结算……」 | 持续技能按 5 种类型改成**瞬时结算**或**本场状态**，不再有可重复的 N 秒自增益（§4） |
| 「充能 1（每 2 秒最多一次）」 | 数值没按时间比例换算，又用限频压收益 | 加速、充能按大巴扎比例放大；卡面不写「每 N 秒最多」（§3.3、§3.5） |
| 「原来的技能效果和范围要继承」「御敌的锋锐为什么是一条线」 | 改写时重造了技能，没以原技能为骨架 | 首行就是原技能：原范围、原目标数、原状态、原倍率换算（§4） |
| 每张卡又长又像（首屏中位 178 字，5–6 行） | 172 张卡都带「部署时」行；再部署改回原作 70 秒后，这行基本只在开局触发一次 | 「部署时」只留给原作本就是部署触发的干员（约 30 张）；卡面最多 3 行 |
| 「感觉很多技能压根没生效」 | 文字有、机制没有或打折，玩家也看不到 | 战后加「本场账本」，每张卡施放 / 触发 / 产出可见（§8.3） |

一句话：**大巴扎的物品是「一个时钟 + 一个动词 + 一条连线」。方舟干员已经有时钟（技力）和动词（原技能），我们要做的只是把原天赋改成那条连线，并把节奏、时长、成长的比例调到大巴扎的分布。** 不是给每张卡再加一层机制。

## 1. 大巴扎实际是怎么运转的（原始库统计）

以下数字都来自原始库字段，不是社区印象。

1. **一张卡 = 一个冷却 + 一个用出效果。** 76% 的物品有冷却；冷却中位 5–6 秒，80% 落在 3–9 秒。用出效果是即时的：伤害、护盾、治疗、灼烧、加速……物品自己身上几乎没有「持续 N 秒的增益」。
2. **持续时间只出现在节奏类效果上，而且很短。** 加速、减速、冻结、充能的众数都是 **1 秒**，约等于中位冷却的 1/5；同一效果再上一次就是加时长，不存在「刷新不叠加」的困惑。
3. **73% 的物品和别的物品有连线。** 连线分三类：
   - 节奏线：给别人加速 / 充能（15%）、给自己加速 / 充能（13%）、控制敌人（11%）。
   - 数值线：本场战斗内给别人加数值（14%）、本场战斗内给自己加数值（16%）。
   - 光环：34% 的物品带常驻光环（「你的武器 +X 伤害」「相邻物品……」）。
4. **成长分三档，比例悬殊。** 本场战斗内成长约 16%；跨战斗永久成长只有 **4%**（英雄池里多在 2%–6%，通用池和 Pygmalien 稍多）。永久成长的扳机约 **75% 是局外事件**：出售（50 条）、战斗结束（11）、购买（7）、选遭遇（6）、每天开始（5）……几乎不由战斗里的施放、击杀触发。
5. **扳机主语按「类型标签 + 位置 + 效果词」。** 战斗内扳机里最多的是「当你使用 [某类 / 相邻] 物品时」，其次是「当你减速 / 加速 / 冻结 / 灼烧 / 中毒 / 治疗 / 护盾时」「当你暴击时」「当物品开始 / 停止飞行时」「当你进入狂暴时」。
6. **限频靠结构，不靠文字。** 频率由冷却、弹药、「每场战斗首次 / 前 N 次」控制；没有「每 N 秒最多一次」。大巴扎技能（对应我们的收藏品）最常见的句式就是「每场战斗前 N 次你使用 X 时，Y」。
7. **卡面极短。** 描述中位 89 个英文字符；1 行 26%、2 行 49%、3 行 22%，4 行以上不到 3%。
8. **升档只放大数字，不改冷却。** 四档齐全的物品里，数值最常见是 1 / 2 / 4 / 8 倍（128 件）或 1 / 2 / 3 / 4 倍（38 件）；冷却 331 件里只有少数在高档缩短。
9. **卡池规模。** 每名英雄 121–162 件专属物品 + 193 件通用物品；技能每名英雄 20–34 个 + 135 个通用。一局能见到的约 300 件物品、160 个技能。

对照进击当前（5680b1d5f）：172 张卡全有「部署时」行；76 张写着「每 N 秒最多」；技力 3–120（白面鸮 100，史尔特尔 4），与职责无关；首屏 3 行的只有 36 张，其余 4–7 行。

## 3. 卡面语法

### 3.1 结构

```
[名] [星] [职业·分支图标] [阵营]           [技能图标 + 技力 N]（可储存 ×2）
① 技能行：原技能名：动词开头的瞬时效果（原范围在旁边画缩略格）
② 连线行：改编后的原天赋——扳机或光环
③ 只有领袖、关键卡、成长卡才有第三行
[小标签] 反隐 · 免疫冻结 · 召唤物 5（同时 3）· 弹药 3 · 阻挡空中
```

- 每行一个从句，**不超过 32 字**；首屏合计中位 ≤ 70 字。
- 原生常驻特性（反隐、免疫、召唤物数量、弹药数、阻挡数变化）做成**小标签**，不占效果行。
- 第三行的配额：3 张领袖 + 约 15 张关键卡 + 约 12 张成长卡，合计 ≤ 30 张。
- 「部署时：」行只给原作本就由部署触发的干员（先锋回费、斯卡蒂跃浪击、缄默德克萨斯剑雨、伊内丝影哨、宴、摩根、耀骑士临光、凛御银灰线等，约 30 张）。其余删除，不另造。

### 3.2 时长只有三种写法

| 写法 | 用在哪 | 重叠规则 |
| --- | --- | --- |
| 持续 N 秒（N ≤ 6） | 加速、寒冷、晕眩等节奏和控制 | 加速：叠加时长；控制：原作规则（寒冷→冻结、取较长） |
| 本场战斗内 | 成长、姿态、本场光环 | 第二次施放的效果必须写在卡面上 |
| 本局游戏内 | 跨战斗成长 | 只能由局外事件触发 |

不写「永久」，不写「刷新持续时间」「不累加」「取原数值」这类结算口径；需要时放进展开的「详细」。

### 3.3 频率

- 卡面不出现「每 N 秒最多一次」。内部保留 **0.1 秒同源去重**，不上卡面。
- 高频扳机（每次攻击、每发弹药、每次受击、每个敌人）改成「**每累计 N 次** ……」。
- 强扳机用大巴扎写法「**每场战斗首次** / **每场战斗前 N 次**」。
- 如果一条连线方差太大（有时 0 次、有时 40 次），换扳机，不靠限频压。

### 3.4 关键词

| 词 | 卡面写法 | 实际 |
| --- | --- | --- |
| 充能 | 为相邻干员充能 4 | 立即 +4 技力 |
| 加速 | 加速你的其他干员 4 秒 | 技力回复 ×2；叠加 = 加时长；图标显示剩余秒数 |
| 弹药 | 小标签「弹药 3」 | 本场战斗最多施放 3 次；打空后技力照涨但不施放 |
| 装填 | 为相邻干员装填 | 弹药回满 |
| 可储存 N 次 | 技能行末尾 | 原作「可充能 N 次」 |
| 再部署 | 原地再部署 | 用户定义：生命回满，技力、增益保留，部署时效果再触发 |
| 当前再部署时间 -N 秒 | 只在再部署流派里出现 | |

关键词用原生 buff 图标 + 颜色高亮，点击出原生提示。

### 3.5 节奏与数值换算

**技力三档**（按卡的职责定，不照抄原作数字）：

| 档 | 技力 | 对应大巴扎 | 适合 |
| --- | --- | --- | --- |
| 快 | 8–12 | 2–3 秒小件 | 原作即时 / 可充能技能（锏 S2、灵知 S2、推进之王 S2、塞雷娅 S2），扳机源 |
| 中 | 16–24 | 4–6 秒 | 大多数 |
| 慢 | 30–40 | 8–10 秒大件 | 由持续技能转来的大招（真银斩、涌潮悲歌、黄昏），终结件 |

原作技力只决定落在哪一档、档内偏前还是偏后。**不要直接用原作数字**：黄昏原作 5 技力、雪境生存法则 5 技力，是因为原作一次部署只开一次或可切换；照抄就成了每 4 秒放一次大招。白面鸮原作 100 技力对应 40 秒持续技能，照抄就一场只放一次。

**时间比例**：进击一场 120 秒、中位技力 20，约为大巴扎（约 30 秒一场、中位冷却 5.5 秒）的 4 倍。由此：

- 充能：常规 **4**，强 6–8，弱 2（不再出现「充能 1」，除非像塞雷娅那样一次给很多人）。
- 加速：常规 **4 秒**，强 6–8 秒。
- 再部署减时：常规 **12 秒**（原作再部署 70 秒的 1/5.5），强 20 秒。
- 控制时长沿用原作数值，不按比例放大。

**升星**：干员属性已经随星级放大（攻击约 1 → 3 倍），所以技能倍率只小幅上调；固定数（充能、加速秒数、费用、层数）按 1 / 1.5 / 2 / 3 或 1 / 2 / 3 / 4。技力**原则上不随星级变**（大巴扎的冷却基本不随档变）；不许出现升星后技力反而变大。

### 3.6 成长

| 档 | 目标占比（172 张） | 扳机 |
| --- | --- | --- |
| 本场战斗内 | 约 15%（25 张左右），优先原作就有叠层的天赋（令「随付笺」、夕「化境」、塞雷娅「莱茵充能护服」） | 战斗内事件 |
| 本局游戏内 | ≤ 5%（8 张左右） | 只用局外事件：购买 / 出售 / 升星 / 赢下战斗 / 每天开始 / 到访某类节点 |

当前收敛到 12 张成长型构筑的方向对；还要核对：跨战斗成长是不是由局外事件触发。

## 4. 技能改编：以原技能为骨架

### 4.1 选哪个技能

选**辨识度最高**的那一个：六星一般是三技能，五星一般是二技能；原作有独特机制的技能优先（凛御银灰 S2 的范围回放、新约能天使 S3 的投送、令 S2 的回收）。不选「强力击」「迅捷打击」这类通用一技能，除非它就是这名干员的招牌（锏 S1 不如 S2）。现状有 43 张选了一技能，需要逐张复核。

银灰现在选的是二技能「雪境生存法则」（原作是可切换的防御姿态），而卡面写的是姿态、运行表里配的是「对 1 名敌人 225% 伤害」——选型、文字、机制三处都对不上。应改为三技能「真银斩」。

### 4.2 五种原技能类型的改法

| 原技能类型 | 例 | 改法 | 重复施放时 |
| --- | --- | --- | --- |
| A. 即时 / 可充能 | 锏 S2、凛御银灰 S2、推进之王 S2、灵知 S2、塞雷娅 S2 | 原样，范围、目标数、状态、可储存次数全保留 | 每次完整结算 |
| B. 持续攻击强化（攻击力 + / 攻速 + / 目标数 + / 范围扩大） | 银灰 S3、能天使 S3、刻俄柏 S2 | **压成一次输出**：在原技能范围、原目标数下，立即结算若干次原技能状态下的攻击 | 每次完整结算 |
| C. 无限持续 / 本次部署内常驻 | 史尔特尔 S3 黄昏、煌 S2、斯卡蒂 S2 跃浪击（部署被动） | **本场状态**：首次施放进入原状态并维持到战斗结束；再次施放只做卡面写明的一件事（如恢复所有生命） | 卡面写明 |
| D. 弹药技能 | 新约能天使三个技能、圣约送葬人、隐现 | 一次施放 = 原技能一轮射击；小标签「弹药 N」= 本场可施放次数 | 消耗弹药 |
| E. 召唤 / 装置 | 令、白铁、梅尔、缪尔赛思、赫默 | 召唤物、装置、投递坐标、影哨在**整备时手动摆放**；技能 = 让它们做一次原技能动作或补 1 个 | 每次完整结算 |

B 类倍率换算：`单次倍率 ≈ 原技能持续期间的总输出系数 × (进击技力 ÷ 原作技力) × 职责系数(0.6–1.0)`，目标数与范围不变。这样不同干员之间的强弱关系跟着原作走，不需要逐张拍脑袋。

**禁止**：可重复发起的「N 秒姿态」；「重复施放结算：……」这类补丁句；为凑大巴扎感改原技能范围或目标数。

## 5. 天赋改编：一条连线

### 5.1 写法

每张卡的第二行来自原天赋，改成下列四种之一：

| 类型 | 句式 | 原作先例（直接可用） |
| --- | --- | --- |
| 扳机 · 喂别人 | 当此干员施放技能时，[对象] [充能 / 加速 / 再部署减时 / 装填] | 银灰「领袖」（再部署 -12%）→ 施放时，你的其他干员当前再部署时间 -12 秒 |
| 扳机 · 吃别人 | 当 [主语] [事件] 时，此干员 [充能 / 本场 +X] | 推进之王「粉碎」（周围有敌人倒下 +1 技力）、令「随付笺」（召唤物被回收 +4 技力） |
| 条件收益光环 | 你的干员攻击 [状态] 的敌人时 …… | 锏「活着的传奇」（攻击战栗目标无视 30% 防御）、灵知「坚冰」（寒冷目标脆弱） |
| 类型光环 | 你的 [职业] 干员 …… | 推进之王「万兽之王」、白面鸮「技力光环」、新约能天使「铳弹协约」 |

原作已经是这种形状的天赋**原样保留，只把数值按 §3.5 换算**。不另造天赋。

自己喂自己（自扳机）只在原作就是这样时保留（史尔特尔 S1「击倒立即恢复技力」这类），每张都要能指出结构相同的大巴扎物品。

## 6. 模组 = 附魔

大巴扎附魔的规律：给物品的用出效果**加一个关键词副词**（Icy = 附带冻结，Turbo = 附带加速，Shiny = +1 多重释放，Deadly = 暴击，Radiant = 免疫控制），数值随物品缩放。

进击模组照此：三星解锁，二选一，每个模组 = 给技能行加一个**原生副词**，写成一行，行首是原作模组名：

- 「附带 2 秒寒冷」「附带 1 秒晕眩」「施放时为相邻干员充能 4」「+1 次可储存」「连击 +1」「施放时获得 2 费用」「本场战斗内免疫控制」……
- 副词优先取自原作模组的主要效果；原作模组没有合适的，再从这张卡所在领袖线的事件族里挑，让模组成为接入另一条线的桥。

## 7. 三位领袖 = 三位大巴扎英雄的引擎结构

当前领袖的三张线核心卡必须进入该领袖遇到的所有商店卡池，来源是大巴扎“英雄专属物品出现在该英雄遇到的所有商店”的结构，不再局限于对应主题店。三位领袖统一执行：核心写在正式领袖属性 `coreCharIds` 中，与该店同品阶普通条目同权抽取；原池已有同名核心时不重复加入，仍受八份来源上限约束。技能、附魔、补给店也可混入核心，核心使用原干员报价与日品质规则，原商品价格、品质和各店刷新规则不变。核心的真实阵营不改。测试工具只读取正式核心这一份：凛御银灰／银灰／灵知，白铁／令／协律，新约能天使／空弦／白面鸮。

### 7.1 凛御银灰（谢拉格）：部署与再部署 ≈ Stelle 的起飞 / 降落 + Dooley 的双核互喂

- **时钟**：原作再部署时间（70 秒级）。只有这条线的卡会缩短它。
- **原作依据**：凛御银灰 S2 原文就有「使『风雪之眼』左侧所有干员部署时以自身攻击力施放一次本技能的范围效果（最多叠加 2 次）」——这是方舟里现成的「部署时扳机」；银灰「领袖」是全队再部署减时；斯卡蒂「迅捷出击」再部署 -10 秒；伊内丝「独影归途」离场并立刻刷新再部署。
- **核心**：凛御银灰（存锋锐，部署时打出）、银灰（施放时全队再部署 -12 秒）。
- **产出者**（让别人部署 / 再部署）：新约能天使 S3 投送、伊内丝、低费先锋。
- **消费者**（部署时效果）：斯卡蒂跃浪击、缄默德克萨斯剑雨、宴、摩根、耀骑士临光。
- **寒冷支线**：初雪、灵知、崖心、圣聆初雪产出寒冷 / 冻结，灵知「坚冰」吃。
- **为什么会爆**：银灰施放 → 全队再部署提前 → 部署时效果和锋锐反复打出 → 「当你的干员再部署时」给凛御银灰充能 → 再存锋锐。

### 7.2 新约能天使（拉特兰）：弹药与装填 ≈ Vanessa

- **原作依据**：新约能天使三个技能全是弹药技能；「火力电台」=「每当友方弹药被消耗……对其攻击范围轰炸」（与大巴扎 Pistol Sword「当你使用弹药物品时造成伤害」同构）；「铳弹协约」= 弹药干员光环；能天使 S1–S3 的连射 = 多重释放。
- **核心**：新约能天使。
- **产出者**：弹药技能干员（每次施放即「消耗弹药」）、装填者（施放时为相邻弹药干员装填）。
- **消费者**：火力电台；「当你装填时」类天赋。
- **终结件**：弹药少、单发极高的干员（Vanessa「巨石」结构）。

### 7.3 白铁（维多利亚）：装置与召唤物 ≈ Dooley 的核心 / 伙伴 / 相邻充能

- **原作依据**：白铁装置「使一名我方干员每 3.5 秒获得 1 点技力」= 大巴扎 Battery（给相邻物品充能）；「节约经费」= 装置损毁时回收；「战地工程师」= 带 3 个、同时 2 个。
- **装置是带自己时钟的「伙伴」**：整备时手动摆放，每 N 秒为相邻干员充能。
- **消费者**：「当相邻装置为此干员充能时」「当你的装置或召唤物被摧毁 / 回收时」（令「随付笺」同族）。
- **为什么会爆**：装置密集的格子里，被喂的干员技力翻倍；装置被打掉又回收，产生「摧毁」事件喂第二批消费者。

## 9. 界面与效果：沿用原版，借大巴扎的信息结构

用户已否决大巴扎配色换皮（10-21）。界面一律用盟约 / 原作组件、字体、图标、特效；大巴扎只借**信息怎么排**。

### 9.1 卡面（商店卡、详情首屏）

- 原生 ChessCard / DetailPanel。首屏：名、星、职业分支图标、阵营 → 技能图标 + 技力数（可储存时显示 ×N）→ ≤ 3 行效果 → 小标签。

- 关键词用原生 buff 图标与颜色；数字只写当前星级，展开后看「a » b » c » d」，当前档高亮。
- 原作技能、天赋原文与属性留在第二页「属性与原作」。

### 9.2 战斗中

- 原生技力条、技能就绪图标、原作同名技能特效。
- **连线可见**：扳机生效时，在目标头顶用原生飘字显示「+4 技力」「加速 4 秒」「再部署 -12 秒」，来源干员短暂描边——这是大巴扎「物品被触发会闪」的方舟版，玩家能看出链条在转。
- 加速图标显示剩余秒数；再部署进度是星标外圈的环（已做）；可储存次数在技能图标角标。

接在原生 StatsHost：每名干员一行——施放次数、伤害、治疗 / 屏障、给出的充能与加速、扳机触发次数、存活时间。对应大巴扎战后的物品统计。它同时是验收工具：某张卡施放 0 次或触发 0 次一眼可见。
