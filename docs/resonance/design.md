# 卫戍协议：共鸣

这是共鸣的可执行设计真源。数值与效果是首轮推演起点；后续修改必须同时更新配置、玩家文案与相应验证。竞品事实保存在 `reference/`，本文件的迁移选择不冒充竞品原规则。

## 体验与内容范围

保留卫戍协议的单人布阵、防线、干员朝向、敌人行进与领袖战。共鸣的决策核心是：用有限金币在追星、升人口、临时补强之间选择；用固定技能和盟约把阵容组织成不同的出伤循环。经营与战斗交替，没有工坊的盟约累计层数或升星奖励。

完整招募目录采用现有设计源的全部 154 名干员，包括工坊活动名单与兼容名单。每人重新分配费用、固定技能、基础属性、三星被动及盟约；兼容条目需要同样通过实战验收。开局环境决定本局招募名单，每局一至五费分别为 14 / 13 / 14 / 14 / 10 名，以保持参照经济下的追星密度。环境保证主盟约的自然成员、对应终端和低费前线，再以种子补足名单；本局完整名单在开局及图鉴可查，未入选者不会偷偷出现在商店。全部干员在相应环境或种子中均可招募，池选择需要覆盖测试。

正常与困难采用二十八个经营节点，轻松也保留二十八个经营节点，但只在偶数节点进行十四场战斗；奇数节点领取后勤补给、经验与免费商店，不增加胜败连续值或胜利奖金。深渊在正常终战后增加两场挑战。经营节点数量与战斗数量分开定义，不拿终战结算后的收入证明终战前能成型。固定补给含装备、有限复制器和定向转职，到账时点与数量见内容契约。既有场地与敌人定义复用，遭遇强度与编队独立配置。

界面沿用工坊的整备、地图与战斗呈现习惯。商店只列干员；经验、人口、利息与连胜败直接显示。详情能查看固定技能的各星效果、装备配方、盟约档位和实际成员。所有文本可选中复制，干员、装备、盟约、节点及详情支持复制定位链接；嵌入画布时有“全屏打开”。开发参数与取证说明不进入默认游戏界面。

## 费用与角色职责

一至五费初始规模为 23 / 33 / 40 / 38 / 20。费用由当前功能和成型位置决定，不沿用工坊六档科技，也不对应原作稀有度。允许低费三星形成稳定主核，四费二星承担多数阵容终端，五费一星提供机制，五费二星完成机制，五费三星提供明确质变。

五费名单：新约能天使、圣聆初雪、凛御银灰、蕾缪安、乌尔比安、隐德来希、史尔特尔、余、维娜·维多利亚、缪尔赛思、耀骑士临光、荒芜拉普兰德、令、黍、重岳、圣约送葬人、烛煌、塑心、魔王、迷迭香。

费用映射以现有设计 tier 为输入，以下为明确迁移，不依赖运行时猜测：

- 原一档保留一费；原二档的普罗旺斯、波登可、格雷伊、送葬人、调香师、协律迁到一费，其余原二档保留二费。
- 原三档的惊蛰、深巡、德克萨斯、赫默、休谟斯、洛洛、蒂比、松果、流星、录武官、地灵、贾维迁到二费，其余保留三费。
- 原四档的哈洛德、锡人、断崖、诗怀雅、海霓、蛇屠箱、空弦、莫斯提马、寒芒克洛丝、水月、莱恩哈特、星熊、流明、仇白、罗宾、摩根迁到三费；魔王迁到五费，其余保留四费。
- 原五档除上述五费名单外迁到四费；原六档的佩佩、贝洛内、裁度、涤火杰西卡迁到四费，其余迁到五费。

每人固定一个体现身份的技能，至少逐项审查技能、原天赋、射程、对空、攻击形状、技力类型与召唤物。万顷、白金、灰毫、奥斯塔、贾维采用各自专属第二技能；令、黍采用各自第三技能，分别支持大小龙融合与播种传送。耀骑士临光采用第三技能，以耀阳与阻挡转真伤承担卡西米尔终端，第二技能的免费部署位不迁入科技人口规则。魔王和海蒂属于辅助，不能按普通攻击输出选作阵容唯一伤害来源；塑心的元素技能保留输出职责。其他选用不因工坊默认值自动定稿。正义骑士号设计固定的被动支援技能，不能保留无技能空白作为共鸣完成项。

罗比菈塔固定使用第一技能和一个玩家预设造型仪锚点。开场锚点免费部署并占用三台库存中的一台；其余两台沿同一锚点轮流部署，每台持续二十五秒，投放间隔至少十五秒，每次部署消耗五点战斗部署费用。仅在罗比菈塔仍在场、锚点格空闲、库存和部署费用均足够时部署；库存耗尽后不再生成。每台造型仪在自身朝向范围内为一名存活近战单位提高20%防御力并提供一层护盾，各持续二十五秒，防御加成不叠加；无合法目标时等待。罗比菈塔退场会收回造型仪并移除其提供的增益，再部署罗比菈塔后库存补充至三台。

基础属性按费用与职责预算拉平，再保留同职责原属性的相对差别；不得把原生最高等级数值直接叠在新羁绊上。生命升星倍率以 1 / 1.8 / 3.24 为起点，攻击以 1 / 1.5 / 2.25 为起点。技能倍率、治疗、屏障、持续伤害、召唤物与被动独立列出三档，不能用同一乘数放大所有效果。普通三星技能原则上明显强于二星，四费三星和五费三星允许超过普通档增长；实际幅度由整局和专项推演验证。

所有原工坊徽章、永久装备堆叠、获得时复触发、亡语复制与其阵营成长不自动进入共鸣。原干员身份与技能机制继承，强度与收益重新配置。

## 盟约设计原则

每名干员基础盟约一至三个，至少一个身份盟约，并按固定技能配置机制盟约；独立盟约占一个名额。装备转职可以额外赋予盟约。不同身份以原生 charId 为准，异格拥有不同 charId，可以分别计数；同一 charId 的重复棋子、召唤物及退场再部署不增加人数。档位即时随整备阵容改变，每场以锁定阵容起算。人数档位不是工坊累计层数。

常规纵向盟约必须明确核心出伤循环、前线需求、主核、挂件收益、转职收益与反制。小盟约可经济或跨场个人成长；成长有对应实例、来源与上限，不能作为所有成员无限累计的隐性盟约层数。大档位覆盖七、八、九、十人；自然成员与转职供给同时验算，不能写出不可达的档位。

必须包含的主逻辑：阿戈尔生命/回复/反击；拉特兰弹药与空袭；谢拉格寒冷/冻结/地板；炎国施法联动；维多利亚高攻击与协同火力；哥伦比亚召唤/机械协作；卡西米尔真实伤害/破防；叙拉古累计伤害与收割；飞行、再部署、控制、攻速、技力、灼燃、凋亡各有独立构筑。每个逻辑均有低费入口、可替换中段与高费终端。

召唤物、机关、弹药雨、冰雪地板、火墙与合击必须在战场可见，并可通过详情了解其来源与作用。表现使用既有渲染事件/场地层，不能只在文字卡说明已发生效果。

### 需求明确的终端

- 阿戈尔：成员生命、恢复、近战阻挡与生命转攻击构成同一循环；受击向周围造成自身生命比例伤害，单独最短间隔，对空可生效。保留可选择的“喂养”分支时，只在本场使用被选供养者的贡献，不永久删除棋子或改变份数。主反击、被动回血、治疗与生命转攻击分别配置上限，避免多段伤害无限自触发。
- 新约能天使：所有拉特兰干员的攻击动作均有概率召来弹药雨，弹药技能的真实消耗另计本场弹药累计。自身开技能在战场范围随机降下十五颗弹药，不擅自替换成优先锁敌；大范围爆炸让落点附近的敌人也可能被命中。空袭倍率随本场弹药消耗增长，并有明确增长上限。三星触发概率百分之百、空袭倍率大幅增加，命中赋予对弹药技能的百分之五十易伤；易伤不错误应用于一切伤害。
- 圣聆初雪：所有可行走地板及保护目标格均铺雪，单格独立冷却。未开技能时，每个寒冷或冻结敌人提供每秒 0.2 独立技力；开技能时，每个提供百分之十攻击与十攻速。三星开启“耶拉之息”并永久保持技能，无开启技能导致的防御/法抗下降；一次攻击只命中一个敌人时，追加两次百分之五百攻击的法术伤害并施加一层麻痹。全场状态计数包括合法空中目标，不把寒冷与冻结同一敌人重复计数。

## 装备、策略与全局环境

装备普通栏位三格，背包装备二十格。两件基础装备按完整对称配方合成高级装备；每个基础对包含明确产物，不允许缺配方造成“全部完成”的空白。合成不消费额外金币，不能在商店刷新装备；开场补给、固定补给遭遇、战利品、策略与任务供给装备。装备退回、拆卸、满栏合成、升星继承及溢出路径必须完整可操作。

合并干员时优先保留玩家明确选中的主实例，否则优先已上阵实例，保持位置、装备、成长；全部被消费实例的装备归并到三格内，其余退回背包。没有背包空间时拒绝本次操作并说明需要腾出的空间，不能丢装备、币或卡池份数。玩家可主动回收任何背包或穿戴装备，不获得金币；界面显示被回收物与效果，回收是玩家明确动作，系统不自行处理装备。

转职来源包含基础配方、定向盟约选择、策略与后段补给。终端大盟约不能只靠极罕见随机掉落；同时不能无限购入转职堆出人口之外的人数。同一干员同名转职不重复计盟约人数。

策略分为即时经营、延迟兑现、条件任务、风险交换、规则改变与战斗机制；环境在开局生效并贯穿本局，策略在中途节点选择。二者分别配置，前者不能冒充后者。完整内容表需包括适用条件、互斥、收益时点、次数/冷却、是否跨场、受益对象、玩家文案以及无效时的替代收益。不能只做一组三选一属性加成。

## 推演与实现边界

经营状态、配置与战斗核心共用，浏览器表现不持有另一套玩法。共鸣独立 API、存档版本、卡池与配置，原工坊行为保持原有规则。拒绝技能选择、越人口、非法配方、重复结算、负金币、过期 revision、绕过份数与破损存档。

日常使用 `recording:false` 的原权威 Battle：不开事件记录、回放帧、逐帧属性采样、视频或内容 trace。必要的最终伤害、治疗、击杀与错误计数用于数值分析。测试覆盖经济边界、全部干员固定技能、各星、各盟约档位、所有配方、转职、触发循环与终端特殊效果。整局推演比较低费追星、高费升人口、生命反击、弹药、冰冻、召唤、元素、真伤与经营成长，不以单一最高攻击贪心机器人代替平衡。

推演后逐次修订：资源获取是否允许目标阵容成型；羁绊人数与星级是否带来预期质量；核心机制是否实际触发且可见；低费与高费是否都有有效窗口；策略是否改变决策；是否出现无限资源、自触发、永久控制或无成本换阵。全部配置与完整用户故事闭环后才运行全面真实浏览器 E2E。磁盘工具持续计入整棵工作副本、正式参考输入、运行区、staging 与发布候选，最终总增量不超过两 GB。

### 成型窗口与遭遇预算

低费追星在五至六级保留合成支线，优先稳定治疗、对空与地面阻挡，再用核心三星换取升人口时间；中费过渡以二星主核加小盟约维持生命，后段再决定留核或换四费；高费路线先把利息转为八至九级招募概率，再投入成星。十级和最高盟约是资源选择，不保证每局所有阵容都达到。战斗内的部署费用用于召唤和返场，开场预选干员依原引擎免费入场；不能把经营金币与部署费用相混。

阵容需要同时应对实际地面路线和空中路线。治疗覆盖前线，远程输出覆盖敌人停留较久的路径；沿路线能阻挡的格与只能远程覆盖的格分别处理。召唤阵容必须留合法造物位置，不能用满十格布阵把自己的机制封住。三星和高盟约提供质变，但缺对空、错误朝向或缺输出仍可以失败。

共鸣按自己的干员预算对原生遭遇加倍率；敌人身份、技能、路径、法抗、移动速度和抗控保留。重甲依然要求破甲、法术或真伤，调整防御与生命不消除这些反制。倍率在原生难度和波次倍率之后生效：

| 难度 | 常规生命 / 攻击 / 防御 | 终局护卫生命 / 攻击 / 防御 | 领袖生命池 |
|---|---|---|---|
| 轻松 | 0.55 / 0.75 / 0.30 | 0.65 / 0.80 / 0.30 | 0.40 |
| 标准 | 0.65 / 0.85 / 0.35 | 0.75 / 0.85 / 0.35 | 0.50 |
| 困难 | 0.90 / 1.00 / 0.65 | 0.95 / 1.00 / 0.65 | 0.90 |
| 深渊 | 1.00 / 1.00 / 1.00 | 1.00 / 1.00 / 1.00 | 1.00 |

领袖生命池独立缩放，不再通过普通单位生命倍率重复放大。共鸣终局最多一百八十秒；领袖漏入目标且无剩余敌人或后续敌人任务时，按失败立即结算。不会等待其他玩家场地处理共享生命池。正常战斗的漏敌生命损失与失败判定保留原规则，减免成零的漏敌仍不算守住防线。
