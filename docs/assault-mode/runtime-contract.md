# 进击运行时接口与验收契约

本文件把已完成的玩法设计落实为模块边界。它不替代逐卡与体系设计，也不宣称实现完成。原始输入只读；全部实现位于当前固定职责簇。

## 内容入口
- 正式模式目录 server/modes/assault/；可在浏览器运行的规则与目录数据视图 shared/assault/；战斗内容 server/sim/content/assault/；客户端 public/js/assault/，独立入口 public/assault.html。
- 浏览器战斗和服务端快测同一 Battle、同一数据和固定步长，模式名字 assault。所有172身体在第一次setupUnitKit前有显式进击KIT。安装失败、缺固定技能或未知效果必须抛错，不能回退generic冒充完成。
- 复用最新上游0.2.5物理职业profile、范围、单位和伤害；不安装旧盟约/驻防/机变/策略/装备域。干员源天赋和模块只跑进击明确计划；不得额外跑旧KIT和原生模组白值/traitMods。
- 工坊已完成的纹理、特效、自然飞行跳字、资源URL与原子会话机制复用；在途且缺依赖的整套入口不盲目复制。

## 数据与身份
- 节点/遭遇/战斗共用 data/assault-design 真源；源码编译器读取 canonical data/assault-sources 绝对路径，不复制源表进每个worktree。
- 干员身体以真实charId为键，源输入完整成长/特性保留来源。基值按design.md插值、分支中位数与一次生命乘五；默认0信赖/0潜能、无原生模组数值。三套阿米娅独立profile但一个购买身份。
- piece.uid是局内购买身体，ownerUid只能是真实主人uid而不是charId字符串。来源份数、星级、形态/模块、永久成长、附加标签、已领取标记在合成与切换后有唯一所有者。
- 明确机器策略/每角色处理器承接270种人类触发描述；禁止运行时正则猜中文后静默选通用伤害。逐个技能效果、天赋绑定组、模块记录可查对应处理器/断言，未知项在实现覆盖检查中失败。

## 引擎
- 进击瞬发和被动无上游nextCastAt攻击间隔第二道节流、无手动/旧3秒自动冷却；其它模式仍保持原生行为。技力费用小数最低0.5，回复/charge按净实际入账；自动技能只在行动检查结算完队列后开始。
- 统一行为事件至少区分attack/hit/skillStart/skillResolved/heal/shield/statusApplied/debuffApplied/elementBurst/ammoUsed/reloaded/deployed/redeploy/death/summonSpawned/summonDied及局外购买/小时/合成。生命回复hpRegen与真正治疗分别处理。
- 每条派生路径保存visited(passiveKey,targetUid)，观察者兄弟路径独立；效果队列按固定顺序排空，不同步递归施放，免疫/失败状态不发成功，光环保活不发新施加。每个角色星级/模块参数在确定时读取一次并实际参与作用。
- 再部署语义按设计；存活满血保留SP/弹药/状态/技能/攻击，倒地立即原位入场；银灰额外施法只屏蔽该次skill的redeploy动作，不屏蔽其它组件/被动或未来施法。
- 敌方各元素独立反复爆发，无旧epPending/冷却锁；同类爆发实例叠加，余量保留。友方、本体原规则保持。原生首领伤害上限如需取消，仅进击指定参数，不全模式修改。
- 真实召唤物库存/场上容量共享主人账、自动格位、费用与回收明确；装置/陷阱/傀儡/融合不得用白板占位。工坊修复台是进击派生模板，原生pile3仅作外观/范围来源。
- 单场快测recordReplay:false，事件逐次drain不积压；样本/失败trace仅保留有用摘要。生产最多保留当前战斗的有限回放或固定种子/操作记录，不能为每场堆全帧录像。

## 局内事务与前端
- createRun、applyAction、previewNodes、prepareBattle、settleBattle、export/import使用独立会话域。动作显式opId与expectedRevision；重复相同动作只回原结果，改参数复用id失败；容量/目标/资金/合法格位先预检，失败不花钱、不抽随机数、不部分修改。
- run包含领袖、固定seed、day/hour/phase、gold/xp/tech/hp、pieces、unique relics、当前三个节点/商店/事件/战斗/奖励、下一战效果、事件已访问与成长/领取账。无服务端持续战斗计时器、无浏览器采集在快测阶段。
- 29商店/26事件每个选择/72收藏品实际可获取且有效；无候选、取消、满容量和缺目标都有明确处理。战败仍推进但不给胜利奖励，终局须真正胜利。
- 独立完整界面：领袖、节点预览、买卖刷新/星级合并、可选收藏品、事件目标选择、布阵/方向/形态/模块/召唤预设、战斗暂停/速度/详情、结果/续局/重开。保留原画风与原始干员/敌人演出。
- 主界面仅游戏事实。文本可选中复制，组件有明显复制定位链接与直达链接，重叠可循环选中；入口有小全屏打开按钮。技术ID/模型/来源证明只放用户主动打开的诊断内容。

## 验收与资源
- 内容覆盖矩阵按172身体、4星、所有可选模块、逐卡效果/天赋、72收藏品、26事件全部选择、36遭遇、29商店闭合；仅数表或循环不算战斗行为验收。
- 先定向引擎因果/单角色/连锁测试，再有代表性的定种子整局与三领袖平衡；所有实际技能支持和资源齐备后才最终全面真实浏览器E2E，不提前开游戏browser。
- 全部新增source/input/worktree/build/日志/录像/temp/runtime与原生工人存储计入2,000,000,000字节；原生Git对象增量计入，原始资产/依赖按canonical绝对路径复用，不可写链接，不全量复制下载。
