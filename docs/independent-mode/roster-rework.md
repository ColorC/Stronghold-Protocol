## 规模与分配依据

截至2026年10月7日，PRTS国服目录按独立干员对象统计为431项，包括异格、联动、作业平台及阿米娅另外两种职业形态。客户端表中429个可获得基础对象，加两种职业形态，与这一口径一致；召唤物、陷阱和不可获得NPC不计入。[PRTS国服目录](https://prts.wiki/w/PRTS:Gameinfo/国服/干员一览)、[PRTS数据检查](https://prts.wiki/w/PRTS:Cargo检查单)。客户端社区镜像采用原生Git版本 `a550f5e048bb94e7cdefc6eb97a4091f0c4c7add`，它不是官方托管地址。

按直接收益分类为纯战斗22、成长45、经济5、生成18、联动7、一次性工具4。这里的工具指获得时提供工具的角色，工具自身仍按部署或撤退事件生效。这一功能分类与参照卡池使用同一口径；成长型不能只因具有阵营条件就归入联动型。

从现有可运行的120个干员本体中选出101个：原目录112人保留93人，新增8人；停用的19人仍保留定义以兼容存档。这不是将431名干员全部加入游戏，也不是把127张随从逐张强行一对一对应101人。暗月全量译稿继续作为效果参照；现有工程部特供规则保留。

897个原生技能木桩场景覆盖120名干员、299个技能选项：单体零防零抗、单体800防40抗、四目标零防零抗各299例。每例运行90秒，无装备、无工坊特质，召唤物伤害另计入总DPS。它只帮助判断输出形状和倍率，不能据治疗者的零DPS判弱；科技还考虑射程、阻挡、控制、治疗、部署周期和附带经济价值。集中表列出了默认Lv4技能、技力条件、原生天赋和各场景最佳输出，默认技能与最佳输出技能明确区分。

例如，玛恩纳、隐德来希、乌尔比安、圣约送葬人等保留高科技纯战斗定位；红豆、艾丝黛尔保留低科技战斗定位。治疗成长由实际有效原生治疗触发；装备治疗不回流产出，群体治疗同一施放只计一次。完全溢出的治疗不计，部分溢出但确实恢复生命的治疗仍计。原生控制、承伤、闪避、技能启动和护盾事件分别承载对应成长。

阵营使用PRTS的国家、组织、团队及所属关系，当前覆盖32个标签；不把出生地或种族当阵营。锡人可以满足所有工坊阵营特质，但它的原生阵营仍是哥伦比亚，交接资格也按原生阵营判断。十二种交接凭证保留，独行者许可由崖心提供，惊蛰可以交给科技2–4的炎阵营干员。

巨锤使用当前攻击力，不使用原次攻击伤害作为基数。攻击力1000、零防御时，一件每动作额外500伤害；五件为900。攻击间隔0.78秒、攻击475的山，单目标裸值收益约305伤害/秒；攻击1317、间隔2.5秒的乌尔比安约263伤害/秒。密集敌人会增加收益，但相邻整格间距1格也不自动进入0.9格范围；高防御还会单独削减溅射。这是采用50%起步、每件加10个百分点的依据。

精准的收益取决于防御和攻击力：攻击1000对800防御，一件使单次物理伤害由200变360；面对零防御则没有收益。对40法抗，一件使法术伤害倍率由0.60变0.68；对80法抗则由0.20变0.36。真实伤害不因此提升。

突袭的一件攻速窗口，对基础攻速100/150/250分别使攻击频率变为1.30/1.20/1.12倍；它不是全程持续增益。空降一件对40法抗的选定格造成9000伤害，受到再部署周期、落点及后续敌人入场时点约束。融毁虽然全图爆发很强，但只能触发一次，下一次70秒的再部署会延长为140秒。

坚守一件在没有额外护盾时，一次非持有者来伤的队伍总生命损失为 `0.8 + 0.2×0.9 = 0.98`：主要价值是重新分配承伤，而不是全队直接减伤20%。五件对应 `0.6 + 0.4×0.7 = 0.88`；高层数上限属于长局叠装，不能当作初始战力。

以上是首轮可玩的平衡参数，不表示最终平衡已经收敛。后续应按真实装备获得率、不同布局、关键组合和玩家反馈继续校准。

## 属性乘区

徽章按件数线性增加比例，不逐件复利：攻击白值2%、基础攻速2%、生命白值3%、防御白值2%、攻击加成2%、自然技力回复基础值2%、法术减伤0.5%、初始技力为所选技能消耗2%、闪避1个百分点、每秒回复原生生命0.1%、旧生命加成徽章3%、治疗量1%、物理法术减伤0.5%、再部署缩减1%、普通攻击伤害1%。现有闪避、减伤、再部署及技力上限仍生效；原生自然回复为零的干员不会凭徽章获得虚构的自然回复。

白值与技能加攻分桶。以原生攻击1000、技能攻击加成200%为例，一件白值攻击徽章为 `1000×1.02×3=3060`；一件攻击加成徽章为 `1000×3.02=3020`。同属造成伤害加成的原生30%与新增1%加算为1.31倍；脆弱、攻速、暴击与额外伤害按其自身结算关系处理。这是用户指定的工坊乘区转换，不宣称完全复制原版所有伤害公式。[PRTS伤害与属性基础](https://prts.wiki/w/游戏数据基础)。
