# 第一期内容设计：干员自有特质、徽章与附加效果

对玩家的名称是「卫戍协议：工坊」（内部名：罗德岛战备演习），暗月奖品对玩家称「工程部特供」。本稿覆盖现有112名可招募干员。普通和精锐不是两名干员；原战斗技能、天赋与培养选择保留，酒馆自有特质、经济和局内成长可以直接属于干员。另行设计的可转移装备与外来附加效果独立列出。本稿已实装；整局平衡仍是首版。2026-10-06 之后的修订已并入正文，逐条见文末「修订记录」。

## 本次定下的规则

- 交接资格是稀有装备「交接凭证」：12名干员获得时自带一件，不显示等级、不计装备总等级、占一格装备容量，不随交接转移；取消所有科技等级1干员默认可被继承，也取消通用接力铭牌。（10-06 修订，原为不做成装备的本体词条）
- 商店只卖干员；全部装备经干员获得（自有特质产出或获得时带来），工程部特供与交接凭证另计。单个干员最多穿戴999件装备。（10-06 修订）
- 装备库存最多20格：每种物品按普通与精锐分格，同一格叠放不限数量（例如攻击徽章×30只占一格）；需要新格而20格已满时，新产出不入库，产出栏标「库存满」；留待使用的工程部特供不占格；库存合成精锐要开新格时同样受限。库存在界面上平铺成格子，把格子拖到干员身上即穿戴（徽章整叠穿上，需要指定干员的补给直接用在该干员）。（10-06 修订）
- 干员自己产出的徽章（特质、它穿的装备、战后产出）直接穿在身上；特质点名其他干员时穿在对方身上（身前一格、场上装备最少的干员、人数最多阵营里装备最少的干员）。功能装备、补给和工程部特供给的徽章仍放进库存。（10-07 修订，用户选定「徽章直接落点，装备进库存」）
- “可被继承”和“可继承其他干员”是两个方向。旧干员穿着的给予凭证符合新干员，或新干员穿着的接收凭证符合旧干员，满足任意一个完整条件就能交接；另一方向不符合不会否决已成立的方向。
- 资格限制使用角色原生阵营、职业与科技等级。限制中的等级指干员科技等级，不是星级、装备等级或精锐状态。调和识别牌、锡人的全阵营标签不能伪造原生阵营。精锐不会自动提高科技等级，也不会解除限制。
- 交接会失去旧干员的原生身材、技能、天赋、自有酒馆特质，交出方穿着的交接凭证随之失去。新干员使用自己的本体能力，只接收允许转移的装备及满足对象限制的外来附加效果。新干员还承受接装损耗：其原生基础攻击力与原生最大生命值降低20%，先扣减再计算装备贡献。这是首版数值；同一身体只扣一次，不能通过晋升、赠送、复活或重新部署清除，也不会随再次接装叠加扣减。转移装备提供的属性不扣减。
- 装备等级独立于调度中心科技等级。全部基础徽章一律一级；备战与战斗都在干员身边显示实际装备总等级。
- 原装备逐件迁移，旧的两装备槽、层数道具、跨全场复制和无资格自动换本体不能原样保留。下面逐项给出改写或停用结果，没有并行的“旧版装备池”。

## 效果归属

本体能力、装备、外来附加效果分别设计，不能因为一个效果需要保存或显示就把它包装成装备。

| 归属 | 设计与转移规则 |
| --- | --- |
| 本体能力 | 原技能、天赋和自有酒馆特质属于干员，出生时直接生效。自有特质可以在获得时带来装备（如交接凭证、各条装备线），带来的装备按装备规则处理。继承时旧本体退出，新本体保留自己的能力；不搬运自有特质。 |
| 装备 | 徽章提供简单属性；功能装备提供独立机制。只计算实际穿戴的装备等级、数量和容量，能否转移及是否唯一逐件规定。 |
| 外来附加效果 | 通过明确奖品或授训来源赋予干员，不是出生特质，不生成物品、不占装备格、不计装备等级。每项单独规定接受对象、触发方式、次数与转移条件。 |

交接资格是稀有装备「交接凭证」（2026-10-06 用户裁定，取代原「本体词条、不附送资格装备」）：这12名干员每次被获得（购买、招募、复制都算）时自带对应的一件，直接穿在身上；三份合成精锐时只留一件，不需要选择。凭证不显示等级、不计装备总等级，但占一格装备容量（上限999件）；不随交接转移，交出方的随之失去；商店、随机装备与奖品都不会出现。普通与精锐限制相同。其他100名没有凭证，但符合对方凭证的对象限制时可以参与；判定只看双方身上穿着的凭证。

例如角峰可以被没有凭证的科技等级2送葬人继承；休谟斯也可以被带着接收凭证的宴继承。幽灵鲨不能被泡泡继承：幽灵鲨要求阿戈尔接收者，泡泡要求重装给予者，两边都不满足。没有资格的一般干员不能自由换成高科技载体。

身材损失不等于只在文字上说“换本体”。以水月接收阿戈尔旧装为例，不计装备时，其原生攻击力从692降到553，原生最大生命值从1336降到1068；旧干员的原生属性全部消失。装备总等级可能很高，但零阻挡、慢攻击间隔等战斗本体特点仍保留，不能因此等价替代重装。

交接仅在休整期执行，新旧本体须适配同一个部署格。先检查资格、对象、地形、同名唯一与999件容量，再显示旧、新身材、自有特质、完整装备及附加效果变化预览。确认后旧干员按正常出售结算一次，允许继承的装备整体转移，不可继承的装备销毁；外来附加效果只有满足接收对象限制才转移，不满足的随旧本体消失，须在预览中明确列出。新干员保留自己的本体能力、既有装备和附加效果。转移不重触发获得或购买，不重置装备计数、已用额度与标签选择。检查失败时整个操作不执行，不提前出售或扣钱。

交接凭证本身不可继承；其余“装备或附加效果可继承”只表示合法交接发生后该内容能否转移。凭证的对象限制、装备转移属性和附加效果对象限制必须分别显示。旧本体的自有特质计数一并退出，新本体保留自己的已有计数；转移的装备和附加效果保留自身状态。

## 装备等级、升级和显示

装备总等级等于所有已穿戴装备等级之和；重复基础徽章按件数相加。库存物品、尚未使用的补给、玩家设施和战斗临时增益不计入。12件一级基础徽章、一件四级功能装备与一件六级功能装备，总等级为22。自有特质、交接凭证和外来附加效果都不计入。

- 全部基础徽章不能合成升级，始终一级，每件占一格。数量可以合并显示，例如“攻击徽章 ×12”，仍占12格、贡献12级。
- 干员没有默认出生作战记录。晋升时升级该干员的自有特质，不生成有等级的档案，也不升级身上所有装备或附加效果。
- 原装备改写后的普通等级沿用原等级；有精锐版的装备在库存中用两件同名普通装备合成一件精锐装备，精锐等级为普通等级的两倍。只合成一次，不继续无限升级。标为唯一的装备，精锐版与普通版视为同名，只能保留一件；标为可重复装备的则允许混合穿戴，贡献分别累加。已经穿戴的装备不能拆下来参与库存合成。
- 调和识别牌、新增共用装备与奖品专属装备各有固定等级；本期没有精锐合成版本。等级不会再额外提供一层通用属性，效果以各自说明为准。
- 普通出售会销毁全部穿戴装备；装备不能主动拆卸或替换。三连保留装备与合法附加效果，并使用精锐本体的自有特质；其他同名唯一冲突须在预览中选择保留一份，多余部分销毁，不回到库存。超过999件则拒绝整次合并。三份同名干员各自带来的同一件交接凭证合并为一件，不需要选择。三连成精锐时获得一次晋升奖励（原版规则）：从科技等级为「调度中心等级+1」（最高6）的干员中随机给出3名不同干员，免费任选一名；该等级不足时用低一级补足。直接晋升的道具不触发。

备战时，干员卡片与部署格右下角常驻一行实际“装备总等级”，例如上例显示“装备22级”。点击角色后，自有特质、装备和附加效果分别展开；装备详情显示名称、等级、数量、效果与转移属性，交接凭证列在装备里并标明「交接凭证」。交接预览同时显示总等级变化、原生攻击力与生命值变化，并列出自有特质消失、新本体能力及保留的附加效果。

属性计算先扣除接装损耗，再增加装备提供的固定攻击力、生命值和防御力，之后按原属性规则结算装备百分比、自有特质与原技能、天赋。徽章放大装备只放大对应徽章的贡献，放大类装备同名唯一；不同放大效果相乘，不重复提高徽章数量。装备护盾每层抵挡一次来自敌人的伤害，触发后消耗一层，最多两层；不抵挡装备导致的生命流失，也不覆盖或刷新原生护盾。

战斗时，在生命条旁显示同一个装备总等级；默认不展开装备清单与经济说明，点选角色后再查看详情。战斗开始时新获得的实体装备立即计入总等级，临时护盾层数与技能增益不计入。仅由战斗事件预约、战后放入库存的徽章在当场不提高总等级，装备到角色身上后才增加。

## 前中后期、替代与操作频率

| 路线 | 阶段选择与输入量 |
| --- | --- |
| 获得与买卖供给 | 前期用惊蛰、角峰、洛洛等获得型供给，德克萨斯、格雷伊、松果靠售出；装备线干员获得时带来指定装备，同阵营的两件可以凑成组合，但其装备资产不必马上全部穿戴。中期先找符合交接限制的接收者，再决定在哪个身体上积累可转移资产；没有合法接收者就保留库存并更换生产角色，不能把旧身体的装备任意搬走。后期降低反复买卖次数，把库存装给最终战斗位。换人会失去原生产干员的自有特质，只保留合法可转移资产。操作较多：购买、出售、刷新与分配；铃兰的开始复演可以降低重复购买的需求。 |

| 弹药与控制供给 | 圣约送葬人、蕾缪安按自身耗弹产出，初雪负责冻结条件，菲莱按友方开启技能次数产出，风笛按前三次击倒产出。缺冻结核心可转技能或击杀供给，不能把寒冷当成已经冻结。后期优先满足守场与输出需求，产量高但过不了关的角色不能取代战斗位。操作较少：选技能与安排站位，实际产出自动结算。 |
| 受限交接 | 干员自己产出的徽章直接穿在身上，交接时随身体一并转移（交接凭证与特殊战斗装备除外）。中期选择一次关键交接，核对科技、原生阵营、职业与地形，承担旧本体退出和新本体接装损耗。后期招募带来合适装备的干员直接给当前身体，减少再次搬运。操作集中在少数换人时：完整预览后一次转移；不按徽章种类拆包。 |
| 治疗与生存 | 古米开场给自身与相邻友方技力回复，赫默、刺玫开场给护盾，砾倒下时给护盾，瑕光部署后减伤，华法琳带来的医疗部共生血囊按伤害治疗周围友方；医疗部蓄能电容需要能够接受外部治疗的承伤者。生命够用即可：生命徽章的来源只剩角峰与维娜·维多利亚。蕾缪安第三技能固定锁定间隔不因攻速徽章缩短。操作较少：检查治疗范围、有效治疗与技能条件。 |
| 临时战斗 | 34名干员的特质只在本场战斗有效：开场、部署后、技能开启时给队友加成，友方倒下时叠层，倒下时爆发或给护盾，第3名敌人出现时全场打击，每第N次攻击额外伤害或晕眩，击倒溢出。站位决定谁吃到加成：相邻、同一行、身前一格、同阵营。不占装备、不进库存。操作较少：摆站位。 |
| 纯战斗 | 24名干员没有特质，凭本体技能作战；斯卡蒂、能天使、银灰等六星放在一、二阶，前期就是大身材，后期是装备的最终承载者。 |

通用价格仍为购买干员消耗3采购资金、出售获得1采购资金、主动刷新消耗1采购资金；沿用基础收入和升级规则。战斗部署费用、技能金币与采购资金分别结算。休整开始顺序为收入与延后资金、奖品、开始供给；休整结束供给完成后直接进入主战斗。继承与赠送转移同一实例，不重复获得，不复制已积累装备或附加效果。

复演或复制只读取目标的自有特质，不读取目标穿戴装备（包括交接凭证）或外来附加效果。铃兰复演其中一项获得时锻造或物品供给，排除资金、免费招募、标签选择、复制与复演；白面鸮和塞雷娅分别复制开始或结束的一项自有特质，按自身的位置重新判断条件。追加产物不能再次触发原追加特质。所有限制与上限随实例保存。

## 第二期机制（2026-10-07）

用户指出多数干员只是「某时点给某干员加几枚徽章」，要求参考炉石传说酒馆战棋，大量增加不寻常的获得条件、成长与相乘、复合效果和高级装备。参考效果逐一核对过官方卡牌数据（类型、例子与来源见 E:/WindowsWorkspace/webworks/apps/stronghold-protocol/runtime/independent-frontend-20261006/hs-bg-effect-catalog.md）。下列机制已实装，规则在 server/modes/independent/native.js，干员表与 data/independent-design.json 同步。

（10-07 干员表 v3 起，干员自己产出的徽章直接穿在身上，见「干员表 v3」一节；下面标「v3」的是之后的变化。）「翻倍」「转交」直接作用在干员已穿戴的徽章上。

- **成长**（原型：耐心的侦查员）：干员每在场迎来一次休整期开始，产量永久增加，有上限。雷蛇（防御，+1/轮，至多+4）、格雷伊（出售所得，+1/轮，至多+3）。
- **时点翻倍**（布莱恩·铜须、达卡莱附魔师、瑞文戴尔男爵）：在场时让同类时点的全部自有特质额外结算一次（精锐两次），同类不叠加。铃兰（获得时）、塞雷娅（休整期结束时）、泥岩（售出时）。
- **相邻重放**（小瞎眼）：白面鸮在休整期结束时再次触发身前一格（精锐两格）友方干员的获得时特质，一次性的装备线因此每轮都有。
- **本局累计**（永恒骑士）：按整局累计次数结算，后期拿到也不吃亏。夕（每获得3名干员1枚攻击加成，每次至多10枚）。v3：能天使改为纯战斗。
- **商店预增益**（诺米）：本局此后商店里的每名干员都附带徽章（当前商品也算），刷新越多收益越大。蒂比（攻速，累计至多每名3枚）。v3：阿罗玛改为击倒溢出。
- **徽章增幅**（鲜血宝石增益）：本局全队某种徽章每枚效果永久提高，乘在所有来源上。伊内丝（攻击，每轮+5%，至多+60%）。
- **转交与吞并**（随从滚球、魔焰执行者）：折桠售出时把身上全部徽章转交给场上装备最多的另一名干员；山在休整期结束时吞并商店最右侧的干员，得到它附带的装备，并按其科技等级获得普攻徽章（v3：生命换普攻）。
- **有界翻倍**（石器时代顽石、加重护手）：引星棘刺让身前干员数量最多的一种徽章翻倍（每次至多+6，每局3次）。v3：寒檀改为每第5次攻击晕眩。
- **精锐计数**（掘金者、冲浪的希尔梵）：烛煌在休整期结束时，场上每有一名精锐干员获得2枚攻击徽章。
- **购买后增益**（煮熟的书、石器时代顽石）：v3 起没有干员使用（锏改为纯战斗）。
- **多样性**（光牙执行者）：v3 起没有干员使用（赫默改为开场护盾，诗怀雅改为开场给相邻友方加攻）。
- **不限次的战斗产出**（复仇）：菲莱友方每开启3次技能产出，不设每场上限。v3：砾、休谟斯、伺夜改为临时战斗或纯战斗。
- **战斗中的倍率**：星熊自身防御徽章效果在战斗中变为2倍（精锐3倍）；塑心参战时本方战斗产出的物品数量变为2倍（精锐3倍），同类不叠加。
- **高级装备**（饰品）：熔铸模具（维娜·维多利亚带来）让携带者全部徽章效果+25%；增压臂铠（佩佩带来）在休整期结束时、携带者在场时给携带者攻击徽章，数量每次翻倍（1、2、4…至多16；v3 由生命改攻击并降低上限）。

机器人整局（同一套出牌规则，不会主动利用站位、卖出时机或刷新节奏）：标准局 90 局改前 29 胜、改后 29 胜（突击 10→9、防守 6→8、技能 13→12），报告 E:/WindowsWorkspace/webworks/apps/stronghold-protocol/runtime/independent-frontend-20261006/balance-v2base-normal14-x30.json 与 balance-v2-normal14-x30.json。这只说明数值没有整体失控，不说明这些机制在真人手里的强弱。

## 干员表 v3（2026-10-07）

依据：酒馆战棋单人池273张逐张标注（报告 E:/WindowsWorkspace/webworks/apps/stronghold-protocol/runtime/independent-frontend-20261006/hs-bg-tier-analysis/report.md，画布卡「酒馆战棋随从分布与干员映射（10-07）」）。现版本以永久成长为主的占47%、临时战斗力18%、生成15%、纯身材9.5%；一阶60%是战斗侧，五、六阶50～60%是成长。改前我方约69%是成长，临时战斗为0。

用户方向：「明日方舟就是纯粹的战斗能力了，你当然可以把六星干员放在两本，很合理的，作为一个没有额外效果的战斗型干员」「很多随从都不是针对于长期buff的，很多都是战斗时临时buff」「特殊战斗装备应该和数值区别开，没必要继承」「生命值是够用就行，伤害却是多多益善」。

- **分布**：纯战斗24、临时战斗34、成长29、经济6、生成11、联动8；各阶人数不变（16/17/19/22/19/19）。
- **纯战斗**：没有特质，凭本体技能作战。六星下放：斯卡蒂到一阶，能天使、银灰到二阶，本体仍按原等级档，比同阶身材大；刺玫、折桠升到三阶，蒂比升到四阶。卡池份数按本模式的阶位计。
- **临时战斗**：只在本场战斗有效，不占装备、不进库存。开场加成（古米、宴、灰毫、诗怀雅、雪猎、蛇屠箱、信仰搅拌机、浊心斯卡蒂、耀骑士临光、凛御银灰按整备区人数）；部署后（野鬃、瑕光、流星）；技能开启时（莎草、莫斯提马、华法琳、缇缇、纯烬艾雅法拉）；开场护盾（刺玫、赫默）；被击倒时（幽灵鲨加攻、砾给护盾、归溟幽灵鲨与焰影苇草爆发）；友方倒下叠层（海霓给阿戈尔、隐德来希给自身）；第3名敌人出现时全场打击（波登可、灵知、号角）；每第N次攻击（寒芒克洛丝额外伤害，寒檀、佩佩晕眩）；击倒溢出（阿罗玛）；召唤物加成（荒芜拉普兰德）。
- **特殊战斗装备**：五件机制装备取代十件纯数值装备，都不随交接转移：拉特兰跳弹模块（弹射）、阿戈尔裂潮重刃（溅射）、医疗部共生血囊（造成伤害时治疗周围随机友军）、谢拉格雪境猎印（盟约脆弱）、维多利亚荆棘纹章（盟约庇护）。盟约按携带者所属阵营计，携带者没有阵营时只对自身生效。
- **停产**：源石促效溶剂、叙拉古仪仗正装、精准狙击镜、歌利亚防护盔、阿戈尔沉海重刃、加速维式重锤、有限加速器、休眠子裔、拉特兰调速器、医疗部稳态仪、近战训练记录仪，以及法抗、闪避、生命加成、调和、减伤、再部署六种徽章；罗德岛采购券只由工程部特供发放。旧存档里已有的照常生效，凯瑟琳的随机池不再出这些装备。
- **徽章落点**：干员自己产出的徽章直接穿在身上，见文首规则。
- **生命与伤害**：成长侧伤害类与生存类约4:1，产出生命徽章的干员从约15名降到角峰、维娜·维多利亚两名；增压臂铠改产攻击，上限降到16。
- **待定**：数值标「待测」，以机器人整局和试玩再调。
