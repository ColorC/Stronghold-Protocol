# Reusable browser recording

`public/js/recording/` contains page-agnostic capture pieces. `startPageCapture({ rrweb, emit, doc, win })` records a rrweb DOM stream with canvas recording disabled, and sends compact interaction and text-selection events through the supplied event adapter. It returns a cleanup function. Clicks, pointer movement, wheel/scroll, keyboard, and focus changes are timestamped; normal text-field input is retained for replay, while password fields remain masked. Text selections record their text, viewport rectangles, and explicit clear events.

`createCanvasMediaRecorder({ stream, options, onChunk, onError })` wraps `MediaRecorder` for a compositor-provided stream. The renderer owns which pixels enter the stream; a game adapter can composite its WebGL layers first. `fitRecordingDimensions` and `resolveMediaOptions` provide the shared sizing and bitrate defaults. Current defaults cap the long edge at 1280 pixels, sample at 24 fps, and request 900 kbps WebM; `recordMax`, `recordFps`, `recordBitrate`, and `recordChunkMs` URL parameters can override those values within bounded limits.

The independent-game adapter remains under `public/js/independent/`: it provides the recording API, the game-specific field compositor, action notes, and a persistent lobby/game control. Use `?record=1` to start as the page loads, or use the visible controls to start and end a recording and open its replay. Recordings made from the lobby carry `surface: "independent-lobby"` and do not require a game session file. Older session-linked recordings retain their existing metadata and replay path. Selection events carry set/clear operations, viewport-relative rectangles, selected text, and event timestamps; replay uses the same timeline for selections, rrweb DOM, and native canvas video.
