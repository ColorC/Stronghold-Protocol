# 多角色参考骨架与 DIY 动作对比

将锏、玛恩纳、斯卡蒂、耀骑士临光加入原有 2B / 史尔特尔适配器。现有素材和动画只读。共同点位仍是候选，人体左右和接触未知。

比较入口 `/dev/spine-reference/compare.html`：默认仅显示共同语义骨架，可切换原图叠点；持武器臂用橙色，按动作进度或实际秒同步，允许每列选择各自的原生动画。固定参考尺寸和骨盆原点便于比较姿态，原生骨盆位移另在数据中记录，不能据此把移根消除掉的画面当成角色没有移动。

## 首轮对照范围

2B、史尔特尔、锏和斯卡蒂使用 Attack；耀骑士临光使用 Attack_Loop；玛恩纳没有普通 Attack，使用 Skill_1_Loop，对应技能挥剑而非普通攻击。动作种类、武器、体型不同，不生成一个通用“合格分数”。

每段采样 201 个原生运行时姿态，计算持武器腕相对骨盆的轨迹、二维肩肘腕夹角、上臂方向范围、躯干方向范围和踝点位移。角度跨 -π/π 时展开，缺点不填零。腕轨迹速度峰不是打击命中时间，也不等于真实发力峰。

## 可以发现的候选不足

| 当前动作 | 持武器肘最小二维夹角 | 腕相对骨盆速度峰时的肘夹角 |
| --- | --- | --- |
| 2B Attack | 约 45° | 约 45° |
| 史尔特尔 Attack | 约 132° | 约 177° |
| 锏 Attack | 约 128° | 约 175° |
| 玛恩纳 Skill_1_Loop | 约 30° | 约 175° |
| 斯卡蒂 Attack | 约 94° | 约 94° |
| 耀骑士临光 Attack_Loop | 约 101° | 约 125° |

2B 在腕轨迹最快的一段仍深折肘；它的最小角出现在约 45.5% 进度，腕速度峰约在 41%。玛恩纳也会深折肘，但在约 23% 的较早阶段，腕轨迹速度峰约 40.5% 时已伸展开。史尔特尔和锏在各自腕速度峰也接近展开。这个对照把“折肘本身”与“折肘时序和配合”分开，是可以定位到具体帧的候选问题。

沿此特征回查 `tools/diy2b/visual_motion.py:68`，现有解算器明确使用 45° 计算手腕目标的最小可达距离。本段 201 个采样中有 57 个肘角约为 45°，分布在约 30%–59% 的进度内；这不是每个采样都产生一个独立的审美问题，而是同一限位平台。它说明腕目标与肩肘约束的配合应优先复核，不应只继续换几个角度或上调“合格”阈值。

2B 持武器上臂方向跨度约 246°，躯干方向约 19°；斯卡蒂也有约 229° 的上臂跨度，同时躯干约 59°。锏躯干只有约 10°，但上臂约 167°。因此单独以躯干小或上臂大判错都不成立。结合折肘和轨迹，可优先复核 2B 的肩肘腕链是否在中段过度回折、把挥砍做成局部甩动；这是解释候选，仍需原图和动作意图复核。

## 当前骨架层不能证明的内容

2B 当前 Attack 的两个踝点几乎静止；临光同样如此。当前采样没有给出“后脚跳”的点位证据，不能顺着旧反馈宣布复现。脚点静止不能证明贴图自然、膝部接缝正确或真实接触。

掌面、刃面朝向、绘画轮廓/蒙皮、附件切换和刀光仍需原图层。反手与正手不能由肩肘腕三个点唯一确定。史尔特尔、锏、斯卡蒂和玛恩纳的剑尖尚未校准，不能比较它们的剑尖弧线或伪造刀轴。

新增适配中遇到临光 `F_L_Hand_a`：实际绑定 F_L_Foot 并位于脚部，不能因名字 Hand 将其归到手。锏以 Thigh / Leg 表达髋 / 膝；玛恩纳用 Hip2 与不同前臂、手部变体。这些例子说明每个新素材需要图像、拓扑和当前附件共同校准。

## 后续重点

先对 2B 中段深折肘、上臂回转和身体配合做逐帧视觉核验；把脚底纹理点、掌面、剑刃面和其余角色剑尖补进参考层。使用同一角色其他合格原生动作和 DIY 早期版本复核，降低跨角色风格差异的影响。此轮不改动画。
