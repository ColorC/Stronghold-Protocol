# 进击与大巴扎的规则对照

本次依据为2026年10月7日的官方19.0公告，以及已经取得、同日更新且验证含19.0内容的官方数据库。数据库的原生 Version 字段不是市场补丁号。社区解释只作交叉核验；没有公开的服务器算法不推测成官方规则。

| 体系 | 查证结果 | 进击的落实与转换 |
| --- | --- | --- |
| 商品身份与品质 | 官方库分别配置物品、品质、尺寸、买卖价；每日品质另有概率表 | 干员基础价与一至四星分开。普通店也按天数出售高星；身份等概率无放回。去重为进击质量规则，未找到官方同店去重承诺 |
| 专门商人 | Jay Jay、Pol、Tok's Clocks、Goldie均三件商品、一次刷新，价格分别二、三、三、四 | 职业、主题、机制和品质商店分别筛选；每次到访三格、一次刷新。各店费用与领袖收藏品减费按进击配置 |
| 持有物升级 | 社区解释买入同名同档物品可升级；服务器匹配算法不在官方库里 | 两份同名同星合成；普通供货匹配仍有合法余量的最高持有星，保留部署位置、模组、永久成长和身份。异格与形态不混为身份 |
| 收购偏好 | 19.0 Laurel出售 Heated/Chilled，收购Toy额外加一价值 | 八个职业商店收购本职业时总额加一金币。干员不是原作Toy，这是明确的类型转换；详情出售金额与成交共用规则 |
| 时间与机会 | 官方库每日六小时、小时经验一；官方公告区分小时遭遇刷新与商品刷新 | 保留十天六时段、三选一和原生幂等存档。结束本时段才进入下一步，刷新商品不推进时间，不重抽遭遇 |
| 收入与经验 | 官方16.0初始收入从七变五；原库每级八经验 | 进击起步金币十二、每日八金币及人口经验曲线是塔防经济设计，不写成原作数值。无利息；战斗奖励、时段经验、科技人口分别计算 |
| 主动与固有被动 | 大巴扎物品本身有主动、被动、触发和四档数值 | 干员固定战技对应主动，自身天赋和进击被动对应固有能力，首屏展示效果。第二页展示方舟原作属性、技能与天赋 |
| 独立Skill与强化 | 本地规则表分别列出10项独立战术与13项附魔 | 独立战术拥有自己的等级、商店和升级奖励，不占干员部署人口；附魔商店选择持有干员施加或替换强化。收藏品、战术、干员星级、进阶模组和附魔分别保留身份与结算规则；数量依据 `data/assault-rules/assault-design/system.json` 的 `strategySkills`、`enchantments`。
| 冷却 | 社区词条区分Haste、Slow、Freeze和即时Charge | 进击加速与充能转换到技力；当前不同来源的技力加速按逐卡设计加算。方舟移动缓速和自然技力下的冻结保留原核心语义，不能标成大巴扎冷却减速与停充能 |
| 伤害与续航 | 社区词条描述毒、灼烧、护盾、治疗和再生的不同作用 | 进击沿用方舟分类伤害、元素积蓄和屏障，并按逐卡说明执行持续伤害；未把毒绕盾和灼烧减半硬套进方舟屏障 |
| 空间和联动 | 大巴扎的尺寸、左右邻接和摆放影响物品联动 | 进击在合法地图上采用四邻、八邻、前方格、攻击范围和全场。召唤物、障碍、敌人路径与再部署继承盟约战斗核心，不增加尺寸棋盘 |
| 事件、成长与结算 | 官方19.0具有按小时、日开始、购买、出售和战后等触发条件 | 干员、战术和附魔使用同一配置观察买卖、升级、日开始、小时开始与商店供货等事件；规则明确目标、数值与来源，真实修改成长、货币或商店条件，并以每次交易和事件身份防止重复结算 |
| 补给库存与生成 | Soda Machine每小时从原始八种饮品池生成一件，继承品质；饮品本身出售价格为零 | 独立八格补给箱，机器占两格、饮品占一格，不占干员人口或整备位。每小时只结算一次；箱满跳过，不消耗生成随机数。原库未公开完整分布和缺档处理，进击从同品质合法池均匀选择，不改到其它品质 |
| 日内临时增强 | 原库八种饮品出售时分别改变冷却、玩家生命上限、毒、治疗与再生、伤害、灼烧、护盾或随机强化，期限为日结束 | 实际出售交易授予当前持有干员独立能力来源，合成同源只保留一次，时段推进先过期；后来购入的干员不获得过去的授予。冷却转换到攻击间隔与自然技力，累计缩短上限八成；生命上限按永久基数取整且不直接治疗。毒和灼烧加强原有对应输出，不重复加武器伤害；再生按真实时间片结算，护盾保留原生生成与补充机制 |
| 临时随机强化 | Mystery Flavor仅钻石档，原始随机表有十一种强化及各自权重 | 临时强化最左侧尚未强化的部署干员，无部署对象时选最早持有的整备干员。保留原始十一权重并筛选合法对象，不包含Golden/Shiny；不覆盖永久强化，到日结束后解除 |
| 战后持有 | 物品构筑跨战斗保留，临时战斗增益须区分 | 干员死亡、撤退及召唤结束不删除持有卡；每战重建完整生命和临时状态，永久成长与玩家选择保留 |

官方公开页和原库可核实的商店数据已经接入；表中的塔防转换仍是进击规则。进击与共鸣各自维护内容、存档和机制，不使用共鸣的参照补齐差异。
