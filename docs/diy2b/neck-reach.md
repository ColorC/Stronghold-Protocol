# 2B：伸臂与头颈避让

用户指出上一版刀刃划过自己的脖子、手臂没有展开。此版先做独立的一次斜劈，前一试版保留为失败对照；演示入口为 `/dev/diy-2b-semantic/index.html?variant=clearance`，默认左侧上次试版、右侧新修订，`compare=original` 可改与最初普攻比较。

这次从刀身的空间路径与持剑臂的可达范围看姿态：蓄力时把剑留在身体侧方，降低过度折肘；挥出时把肩肘腕链展开，再短随动、回收。没有加长骨段、缩短剑或扭转剑与手的握持关系。去掉斩击中段的角度关键点，避免平滑插值在中段又停一次；此独立动作只保留一次攻击事件，时间为 0.42 秒，未替换原战斗动画。

生成命令沿用 `tools/diy2b/semantic_attack.py`，新增 `--motion clearance`。默认 `reference` 模式继续生成旧试版。新模型在 `public/dev/diy-2b-clearance/{front,back}.json`，原图和 atlas 使用各自 canonical 路径，所有非 Attack 动画与骨架/皮肤不变。

新增检查使用真实 Pixi Spine 运行时，两个视图逐帧读取模型世界坐标，排除相机影响。头部用 face/hair 附件顶点的保守包络；颈部是针对本 2B、随 head 参考变化的局部保护区。刀身中心线用剑根到剑尖的线段，加有限宽度。它检查整段刀的投影避让，不把“剑尖没过地面”当作刀身安全，也不把遮挡层次当作避让。

手臂伸展度用肩到腕距离除以肩肘、肘腕两段长度之和，分别检查本次指定的蓄力和挥出阶段。此值描述这份平面素材的展开程度，不能作为所有动作的通用伸臂要求。保护范围与宽度也只是本模型的保守检查，不能据此声称已自动识别人类解剖或验证真实三维碰撞。

连续帧检查能检出旧前视的头颈穿越和缩臂，新修订通过这两项，同时保留原有分支、脚下支撑、握持、剑长、地面和静态端点检查。发力、重心、转身和打击反馈仍需视觉判断，这些数值没有艺术合格结论。全部运行证据保存在 canonical 项目 `runtime/2b-neck-reach-20261008/`。
