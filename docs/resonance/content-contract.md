# 共鸣内容契约：首轮推演

本文件把深度设计转换为可实现的表和接口。这里只规定首轮起点；整局推演发现问题时允许修改效果和数值，同时更新配置、文案和验证。参考事实见 reference，以下均为共鸣的迁移设计。

## 配置与身份

正式配置使用 `shared/resonance/catalog.js`，纯 ESM，不依赖 Node 或临时文件。导出 `resonanceContent`，含 schemaVersion、operators（按原正常 chessId）、pacts、equipment、recipes、strategies、environments、campaign。`server/modes/resonance/catalog.js` 将正式配置与 canonical getData() 的原生棋子、技能、天赋、召唤物合成，不导入独立工坊装备、成长或叠层规则。图鉴和战斗用同一配置。

operator 明确包含 id、name、charId、sourceChessId、cost、position、canDeployHighGround、role、fixedSkillIndex、fixedSkillId、pacts、assets、stars[3]。每个星条目含 stats、skillOverrides（spCost/initSp/spType/trigger/duration/bb）、talentOverrides、passive。source引用原生 Git commit 与记录 ID，不使用内容摘要。完整名单154人，费用映射沿用 design.md。

每人一身份盟约、一机制盟约；下述五人再带独立盟约，共一至三个。身份优先人物所属国度，复合阵营归并如下：能天使/新约能天使/蕾缪安→拉特兰，德克萨斯/缄默德克萨斯→叙拉古，哈洛德→谢拉格，炎-龙门/龙门→龙门；原谢拉格/喀兰贸易→谢拉格；雷姆必拓/雷姆必托→雷姆必拓；炎→炎国。原始阵营仍显示在背景介绍。其余取来源第一国度，没有国度则罗德岛。

角色预算：前线由 protector/guardian/centurion/unyield/primprotector/fearless/musha标记；治疗由MEDIC且非incantationmedic标记；控制由原选技带寒冷/冻结/晕眩/束缚/沉睡/浮空/战栗/推拉标记；召唤由非空tokens或dollkeeper/tactician/craftsman/summoner标记。其余伤害。机制优先级：executor/agent→再部署；skywalker→飞行；AMMO→弹药；summoner/tactician/dollkeeper/craftsman→造物；选技含灼燃→灼燃、凋亡→凋亡；固定技实际控制→控制；MEDIC/guardian/bard→共生；pioneer/charger/merchant→后勤；技能SP为attack或fastshot/fighter/funnel→连击；其余法术职业→术式，其余→破阵。不能把只有单位简介包含某词当作机制事实。

## 干员与各星预算

原完整固定技能选型采用 roster-worktable 的提案，除了明确个人S2、令与黍的S3、无技能支援项。令的S3开场一只弦惊，每次施法在库存与部署位有余、合法空格及部署费用足够时再召一只基础弦惊。两只基础弦惊按攻击范围融合，保留一只原位变为高级法伤形态、占两个召唤部署位；吸收的一只触发原天赋。库存四只、最多三个部署位；死亡不返库存，技能结束补一只。技能脉冲仅覆盖正交邻格，三星翻倍与一次合法原位复召仅作用高级形态；黍的S3攻击同时为范围内生命最低友方治疗当前攻击力100%，并以有效治疗播种，敌人在播种格登记进入位置，离开四格以上才传回同一合法格。空中、不允许位移的敌人不传回；种地持续，传送与技能增益只在技能期间生效。每个固定技能必须有原生技能参数出处并通过实际 SkillRuntime 施放。历史原生 Kit 的通用或缺失项由共鸣显式 Kit 补齐，未实现的通用伤害替身不算完整。不能为了掩盖缺 Kit 换回通用技能。角色技能身份、攻击形状、对空、代价、原天赋均保留；重配属性/施放节奏，原天赋数值须逐条预算，不把所有黑板键同乘。

费用的一星前线HP预算 1300/1550/1850/2250/2750，攻击预算 160/195/235/290/350；后排HP为前线0.65、攻击1.15；治疗HP0.7、攻击0.95。同职原HP/ATK相对中位数夹在0.8–1.2，乘预算；护甲保留职别相对值但夹40–500，法抗0–30，bat/射程/阻挡按角色保留。二/三星HP乘1.8/3.24，ATK乘1.5/2.25；三费三星固定技能伤害黑板相对一星乘1.6，四费三星乘2.5，五费三星乘8；二星乘1.2。只对明确 damage/heal/shield 比例键增加，百分比状态/抵抗/概率/时间/弹数不按同一倍率放大。编译器必须存储逐键最终值供图鉴检查。

施放节奏按选技能机制分组后逐人定值：持续/弹药自然技力 cost夹18–40、init=min原init,cost*0.6；攻击回复夹3–10、受击回复夹6–16。持续原值夹8–30，不改原无限/被动；取原节奏中位附近，后续推演按首波/首施法实际时刻调整。白金固定24SP/初始8/自然回复，持续永久；万顷S2 26/初始10/自然；奥斯塔S2 28/初始10/自然；贾维S2 24/初始8/自然；灰毫S2 12/初始4/受击，与炮台零阻挡/高地切换风险相配。正义骑士号固定被动“战线应答”：每6/5/3秒为两格内友方最低生命者恢复自身攻击120/150/220%，同一目标获8/12/20攻速3秒，不获取技力。

普通低/中费三星被动按机制给出额外战术窗口，需在每人条目写具体玩家说明：弹药首技能+3弹；控制首次控制后自身+15技力（每场一次）；造物首召唤多20%最大HP及30%ATK；共生治疗使目标获得治疗额15%盾，单目标2秒CD；后勤首次产费额外5DP（每场一次）；连击每第六次攻击返2SP；破阵对生命低于35%敌人+20%物/法伤；术式首技能在范围内追加100%ATK法伤；灼燃/凋亡首次元素爆发返10SP（每场一次）；再部署首次退场再部署时间减半（每场一次）；飞行腾空时+30ASPD。本项与原天赋并存，不能替代原天赋实现。每人记录精确生效动作，不能只写“加强三星”。

五费三星除上述曲线有如下质变，必须显式运行验证：新约能天使按下节；圣聆初雪按下节；凛御银灰技能范围内每2秒给全员10%自身ATK额外物伤，召唤风雪鹰攻击可对空；蕾缪安每次蓄力射击额外贯穿一目标并溅射80%本次伤害；乌尔比安受击永久成长每场上限20次、每次50HP/5ATK，三星翻倍，锚击波对空；隐德来希首次致死进入8秒不可倒下并全地图破甲40%；史尔特尔首次余烬永久直到退场，每秒自损不超过最大HP10%，每击额外100%ATK真伤；余每第三次攻击砍击直线3格/对空并回复10%最大HP；维娜·维多利亚召出的剑每轮攻击额外600%ATK真伤，最多四剑；缪尔赛思流形最多三个、共享本体30%治疗/技能复制，不额外羁绊计数；耀骑士临光每次技能以目标为中心落耀阳，半径2每秒100%ATK真伤8秒；荒芜拉普兰德技能结束立即再次施放一次（每场一次），冻结改1秒沉默防无永久控；令大龙HP/ATK再翻倍，龙亡后重召一次且占格；黍范围传送对领袖减速20%持续3秒、冷却3秒而不位移，每次传送对普通敌造成100%ATK法伤；重岳连拳每第五次攻击附带400%ATK物伤并对周围一格溅射；圣约送葬人最后一弹返满弹一次/每场，不无限循环；烛煌技能期间火墙贯穿正前方全路径每秒100%ATK法伤并附加10%ATK灼燃损伤；塑心每次凋亡爆发向最近三个未爆发目标传200%ATK凋亡损伤、每目标2秒CD；魔王技能内全员自然技力+2/秒并每3秒一道300%ATK合击；迷迭香攻击溅射半径+1并追加200%ATK余震，原浮空免疫规则保留。

## 经营供给、策略与环境

## 性能与战斗接口

本场机制计数是小的聚合对象（伤害/治疗/弹耗/技能/控制/造物攻击/精英击倒/各机制触发），recording:false仍有聚合，但没有事件、trace、帧、快照、属性采样、视频。禁止记录每个事件再后算任务。

场地静态区域放 replay.fieldMeta.resonanceFloors 一次，动态火墙/音域放每快照精简 floors 列表（稳定id/kind/owner/tiles/until），只活跃区域，单场最多12动态区域；不在每帧重复全雪格。renderer3D与fallback都消费；fast不构造展示列表，只运行效果tile计时器。全雪地板实现需要同格多敌正确独立CD，目标格在内、空中经过格也能受影响。

Battle入口 runResonanceBattle(state,{data,catalog,recording=false}) 返回 {won,hpLoss,result,growth,replay,diagnostics,metrics}；getResonanceField同步提供stage/wave/field/deployMap，prep与Battle共用。原Battle content='independent'、无旧盟约，只安装共鸣extraContent；Kit必须构造前替换。派生HP攻击在同次属性重算应用；ammoSkill标签在弹道发射时固定，链/溅射传递；永久phalanx保留防御是共鸣变体，工坊原行为不能改。
