# 共鸣：阵营赛季

当前赛季为 `resonance-factions-2`，共享配置为 `shared/resonance/faction-season-v2.js`，盟约效果与玩家文案为 `shared/resonance/stronghold-pacts.js`，战斗实现为 `server/sim/content/resonance/stronghold-pacts.js`。原生归属、固定技能与天赋来自冻结的卫戍数据。`resonance-factions-1` 及更早赛季的存档仍按原 seasonId 与原规则读取。

[Riot 赛季介绍](https://teamfighttactics.leagueoflegends.com/en-us/news/game-updates/into-the-arcane-overview/) 提供机制背景；精确数值采用已固定的 CommunityDragon 14.23 客户端提取表，见 [完整参考](reference/tft-set13-14.23.md)。

## 盟约口径

- 阵营盟约是不叠层的卫戍协议盟约：按上阵人数分档，每档写明数值；战斗内效果有上限或持续时间，任何盟约效果都不跨战斗累计。
- 每个阵营有一条改变战场逻辑的机制（通缉、寒冷与冻结、炎佑、复活、装备、隐匿与恐惧、真实伤害与阻挡、技能联动、屏障、医疗协同），与成员自己的技能、天赋配合；纯数值只作陪衬。强度主要放在干员技能与装备搭配上。
- 狙击、术式、坚阵、突袭、技力协同对应原版精准、奥术、坚守、突袭、迅捷的常规机制；其余十一个职业/机制盟约沿用原实现，数值按同一量级修正（见下）。
- 退出新赛季的经济：拉特兰、叙拉古、卡西米尔、哥伦比亚原有的赞助装备、交易市场、宝箱与临时合成；同袍、铸军、圣枪的经济不变。维多利亚5人起每3场战斗发放1件维式重锤。
- 新赛季候选池移除依附被替换机制的强化：拉特兰王冠（TFT13_Augment_AcademyCrown）、晶碎回响（TFT13_Augment_Automata）。领军中号角改为固定的全体友军防御力+8%、法术抗性+8，不随战绩成长。

## 效果与尺度

重做的十五个盟约直接使用原生尺度的百分比、秒数与技力；沿用的十一个盟约中固定生命、屏障、治疗和伤害换算到原生尺度，百分比、触发次数、持续时间、技力、金币与人数保持原义。防护评分通过每名干员的原生防御锚点转换。

废弃的工坊累积盟约层数特质不进入本赛季的战斗记录和原生详情。保留职业特性、天赋、固定技能与实际升星效果。招募价格在费用处显示，免费部署的详情不再混列原版部署点数。

### 拉特兰

敌人出场后，场上生命上限最高的敌人（精英、领袖优先）被通缉；更强的敌人出场或被通缉的敌人倒下时，通缉随之转移。

- 3人：同时通缉1名；【拉特兰】干员对被通缉的敌人伤害+20%。
- 4人：同时通缉1名；【拉特兰】干员对被通缉的敌人伤害+30%。技能获得的弹药+30%，没有弹药的技能持续时间+20%。
- 5人：同时通缉2名；【拉特兰】干员对被通缉的敌人伤害+30%。技能获得的弹药+30%，没有弹药的技能持续时间+20%。被通缉的敌人被击倒时，所有【拉特兰】干员回复4点技力。
- 6人：同时通缉3名；【拉特兰】干员对被通缉的敌人伤害+45%。技能获得的弹药+50%，没有弹药的技能持续时间+30%。被通缉的敌人被击倒时，所有【拉特兰】干员回复6点技力。


### 谢拉格

【谢拉格】干员的攻击使目标寒冷；已寒冷的敌人再次寒冷时会被冻结。

- 2人：攻击使目标寒冷1秒（同一目标每4秒至多一次）；对寒冷或冻结的敌人伤害+15%。
- 4人：攻击使目标寒冷1秒（同一目标每4秒至多一次）；对寒冷或冻结的敌人伤害+30%。场上有敌人时，每20秒刮起寒风，使全场敌人寒冷4秒。
- 6人：攻击使目标寒冷1秒（同一目标每4秒至多一次）；对寒冷或冻结的敌人伤害+45%。场上有敌人时，每12秒刮起寒风，使全场敌人寒冷6秒。


### 炎

开战时在【炎】干员附近召唤“炎佑”。炎佑追踪威胁最大的敌人，攻击附带攻击力20%的灼燃损伤，附近的敌人受到元素脆弱。

- 3人：炎佑的攻击力、生命上限为【炎】干员开战时总和的20%，同时攻击2个目标。
